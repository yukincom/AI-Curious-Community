# 高活動PNへのOFF到来監査とeLN出力の必要性対照

## 結果

**正符号のeLN→PNをOFF到来だけ止めると、PN平均は全8試行で数Hzまで低下した。**

| OFF中の条件 | PN OFF20秒 Hz | 対応する対照からの変化率 | 3 Hz以下 |
|---|---:|---:|---:|
| 停止なし | 132.84〜135.01 | 0.00〜0.00% | 0 / 8 |
| 既知の正符号eLNだけ停止 | 11.69〜11.94 | -91.31〜-91.16% | 0 / 8 |
| unclearだけ停止 | 104.74〜106.01 | -21.74〜-21.01% | 0 / 8 |
| 正符号eLN全部停止 | 3.66〜3.89 | -97.27〜-97.10% | 0 / 8 |
| GABAだけ停止 | 193.29〜194.50 | 43.62〜45.51% | 0 / 8 |

各欄は同じ4seed×2入力利得の8試行の範囲。正符号eLN全部停止は、厳密な3 Hz以下の参考値には未達で、集団平均として数Hzの残留がある。全PNが低発火になったことを意味しない。元の約133〜135 Hzという高活動の維持は大きく崩れた。既知の正符号だけの停止とunclearだけの停止を分けると、どちらも単独では同じ数Hz域に達しない。

前回、PN／LN→ORNの116辺を止めてもPN平均の変化は1%未満だった。今回、**PNの高活動を保つ出力経路として正符号eLN→PNの必要性が支持された**。入口のORN再発火を支える戻り入力と、PNの高活動を維持する出力入力を、介入の対象として分けて説明できる。二つの完全に独立した回路や、すべての残留活動の発生源を確定したわけではない。

主判定とは別の記述として、正符号eLN全部停止後も100 ms窓で発火したPNは 25〜27 / 686細胞、各試行の最大個別発火率は 300〜330 Hz。集団平均の低下を全細胞の静穏と取り違えない。100 ms窓の個別率は10 Hz刻みである。

## 監査を先に行う

回復点は研究ブランチの `7e21ad7`。元回路の8条件をまず再実行し、OFF19〜20秒にPNへ**実際に届いた入力**を記録した。8対照すべてで前回の24.5秒全体の発火記録と完全一致を確認し、入力の独立照合後に `audit-report.json` を作成した。内容を確認し、そのハッシュを `audit-reviewed.json` に保存してから停止試験を開始した。

高活動PNの集計条件はOFF19〜20秒の100 Hz以上。各試行363〜367細胞、8試行に共通する高活動PNは359細胞。全686 PNの集計も併記した。これは入力内訳の記述用であり、停止対象の選定には使っていない。停止先は事前に固定した全686 ALPNで、前に候補となっていたALLN→PNだけを調べた。

| 高活動PNへの送り元 | 正入力総量に対する割合（8試行の範囲） |
|---|---:|
| eLN・ACh | 67.317〜67.535% |
| eLN・unclear | 13.979〜14.052% |
| eLN・その他（octopamine） | 0.184〜0.185% |
| PN | 13.976〜14.142% |
| 残留10 ORN | 0.131〜0.136% |
| そのほかのORN | 0.000〜0.000% |
| ALIN | 0.263〜0.267% |
| その他 | 3.831〜3.977% |

負入力の絶対量は正入力総量の **43.65〜43.81%**。うちiLNのGABAだけで **31.04〜31.21%** に相当する。GABA入力が届いていない状態ではなく、それを止めた条件ではPN平均が増加した。負入力の由来も `audit-report.json` と図へ正入力と別に記録している。

割合の分母は、集計対象PNへOFF19〜20秒に到来した**正のシナプス増分の総和**。`jump` はモデルのシナプス状態 `g` に加える増分で、膜電位への寄与率や発火の因果的説明率ではない。負の増分は別に保存・表示し、正負を相殺した値を「正入力の割合」としない。全PN、試行ごとの高活動PN、共通359 PN、各PNの内訳をそれぞれ保存した。

eLN/iLNはこの固定モデルのALLNの正／負符号による分類。正のiLN入力という別項目はこの分類では存在しない。ORNは過去と同じ `class:ORN,prefix:ORN_` の集合を使う。残留ORNは前回の固定10細胞、そのほかのORNも別項目とした。型名のない `olfactory` classの細胞を勝手にORNへ含めない。ALINと残りの入力も正負別に保存した。

## 停止条件

| 条件 | OFF中だけ止める入力 | 辺数 |
|---|---|---:|
| 対照 | なし | 0 |
| 既知の正符号eLN | ALLNの正符号、伝達物質表記がunclear以外 | 11,069 |
| unclearだけ | ALLNの正符号、unclear表記だけ | 1,769 |
| 正符号eLN全部 | 上記2集合の和。負の入力は通す | 12,838 |
| GABAだけ | ALLNの負符号GABAだけ。正の入力は通す | 6,325 |

「既知」は伝達物質の表記がunclearではない意味で、生体の興奮性が実証済みという意味ではない。11,069辺の内訳はACh 10,944辺＋octopamine 125辺。モデルがoctopamineを速い正入力として扱うことも再現条件であり、生理的妥当性をここで主張しない。負のglutamate ALLN→PNの1,287辺は全条件で通す。GABA停止条件で全iLNを止めたとはいわない。

前回のPN／LN→10 ORN停止は重ねず、元回路から独立に比較した。残ったORN 153948へ届くALINの2辺は介入しない。新たに強かった辺を選んで切る変更も加えていない。

各条件8試行＝同じ4seed（2026091701、2026091711、2026091721、2026091731）×入力利得1.0／0.5。`hungry` / `satiated` は再現用の既存ラベルで、今回新しい空腹生理は足していない。8対照の監査後、seed 2026091701・利得1.0で4停止条件を順に検証。手順ハッシュを固定し、残る7組×4条件へ展開した。初回の4停止試行も最終40試行に含む。

## 到来時刻での介入

無入力0.5秒→ON1秒→OFF20秒→再ON1秒→再OFF2秒。刺激は従来のDM1／VA2 ORN 157細胞へ基準60 Hz×利得。dt=0.5 ms、遅延2 ms、gain=0.65、KC gain=0.25、単一worker、50 ms endTickを維持した。

元のシナプス加算と同じ順序・float精度で、全PNへの全入力と通過予定の入力を再構成する。OFFの積分直前だけ、該当PNの当該時刻入力を通過分へ差し替える。遅延バッファの非零件数を整合させ、入力の相殺が解けて非零になった細胞も通常どおり計算する。

- ON末尾の発信がOFFに届けば停止対象。OFF末尾の発信が再ONに届けば通過。
- ON到来は全て通す。OFF開始時に膜電位や到来済みのシナプス状態をリセットしない。
- 同じ規則を2回のOFFに適用し、再ONでは経路を通す。OFFで履歴が変わるので、再ONの発火まで対照と同じに強制しない。
- 変更は試験用コピーの入力到来だけ。ライブのラボ・本体・2D UI・LLM接続に反映していない。

## 主指標と解釈の範囲

判定に使う値は**PNのOFF20秒平均Hz**だけ。前回の定義を踏襲し、刺激OFF後19.9〜20.0秒の100 ms窓で全686細胞の平均を取る。入力監査の窓は19〜20秒の1秒であり、混同しない。各細胞発火やほかの時刻の記録は照合・説明用に保存するが、別の成功条件を追加しない。

実行前のプロトコルでは3 Hz以下を厳密な静穏参考値として固定した。ユーザーの「数Hzまで低下」と完全無発火は異なるため、参考値の達成件数だけでなく、実測Hzと対応する対照からの変化率をそのまま報告する。たとえば3 Hzをわずかに上回る結果は「大きく低下して数Hzの残留」と読み、元の高活動が続いたと表現しない。

この比較は、指定したモデルと刺激履歴で、その入力経路が持続する高活動に必要かを見る。個々の辺の必要性、eLNだけの十分性、唯一の発生源、生物の空腹状態や独立した二つのアトラクタは証明しない。入口側の前回の介入と出力側の今回の介入を、異なる対象・独立した条件として並べる。以前のDM1増加を特定GABA辺の効果と断定する根拠も追加していない。

## 検証と保存

- 対照8試行の24.5秒全体、4集団＋個別10 ORNの毎1 ms発火数が前回と完全一致。個別686 PNの4時点の累積発火も前回と一致。
- 停止32試行の最初のON終了まで1.5秒は同じ発火記録に完全一致。全試行のON到来停止は0。
- 全40試行、計 **1,344,560,000 PN細胞ステップ** で、再構成した全入力が元の遅延バッファとfloat単位で完全一致。
- 52,534辺×7観測区間の全到来件数を、送り元の実発火数・固定遅延・辺一覧から独立照合。停止範囲はclass、伝達物質表記、符号、到来時刻から別に判定し一致。
- OFF19〜20秒のPN別・由来別到来総量を、各辺の実到来件数×重みで再構成し一致。0.5 msごとの集団合計、境界18,522行／試行、非零件数の差分も照合。
- 由来別double和と元のfloat和の最大差は1細胞・1stepあたり 0.000158429146 mV。floatの加算順による丸め差を明示し、ゲート本体には元順序のfloatを使用。
- 主指標40件は各PNの累積発火差と独立な集団カウンタの時間窓和で一致。入力監査の確認ハッシュ、1 seed後の手順ハッシュ、全試行終了時の実行ソースハッシュも一致。

最初の対照のPython照合時、`olfactory` classだけで型名のない23辺をORNへ分類していた検証側の誤りを修正した。Javaの観測と元のORN定義は当初から一致していた。回路、プロトコル、得られた発火／到来記録は変えず、検証器だけを修正して最初の試行を再照合し、残る7対照へ進んだ。`preflight-validation-correction.json` に変更前後のハッシュと理由を保存。中断からの再開は `resume_audit.py`、新規再現は修正済み `run.py audit` を使う。

`*-topology.csv.gz` はPNへ届く52,534辺の固定メタデータ。`*-phase-edges.csv.gz` は実到来件数と停止件数、`*-source-spikes.csv.gz` は送信元の実スパイク件数を到来窓で分類したもの。この2つと固定辺重みから独立に入力総量を再構成する。`OFF19to20` と `OFF19p9to20` は `OFF` と重なる監査窓なので、全7phaseを排他的な区間として足さない。

`*-late-inputs.csv` はPNごとの到来内訳、`*-late-steps.csv.gz` はOFF19〜20秒の0.5 msごとの全PN集計、`*-boundaries.csv.gz` はOFF／ON境界前後。`*-populations.csv` は毎1 msの元の集団・個別10 ORNの発火、`*-PN-cells.csv` は各PNの累積発火スナップショット。停止条件の `full` は**その停止試行内で実際に発信された入力の停止前値**であり、別世界の無介入対照ではない。

実行ソース、固定上流4ファイル、パッチ、データ／ソースハッシュ、各試行の検証結果、監査を先に行った証跡と手順固定記録を保存した。モデルデータとコンパイル済みclassは重複コミットしない。
