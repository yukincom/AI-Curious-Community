# 第1段階: 障害物なしの飛行学習

このページは第1段階の保存結果。現在のラボでは[柱回避の第2段階](STAGE2.md)も選べ、現在の起動時は[先読み追従の第3段階](STAGE3.md)から始まる。

13個の係数を持つ小さな線形制御器を、環境内で試行しながらCEM（cross-entropy method）で実際に最適化した。固定PD制御の答えや教師データは使わない。ハエの接続回路とは別の、身体と学習環境の基準実験である。

## 再現

Node.jsのみ。研究リポジトリのルートから実行する。出力は既定で同梱結果を上書きするため、新しい実験は別の出力先を指定する。

```sh
node tools/fly-body-lab/training/train.mjs --output .fly-research/flight-training/new-run
node --test tools/fly-body-lab/sim.test.mjs tools/fly-body-lab/input-state.test.mjs tools/fly-body-lab/training/training.test.mjs
```

[重み](run-stage1/model.json) / [学習曲線・全評価場面・実測結果](run-stage1/report.json)。乱数seedは20260916。55世代・各36候補・上位7候補で分布を更新。訓練6場面、選択用8場面、最終評価20場面はseedが重ならない。評価場面は最終選択後だけ読み、学習・モデル選択には使わない。各訓練8秒、選択10秒、最終評価18秒。CPUで実行し、初回は約7.2秒。継続学習やバックグラウンド再学習は行わない。

## 何を入力しているか

プレイヤーとの位置差、身体の速度、身体位置の上昇気流、温度。プレイヤー位置は世界が与える正解情報で、画像からの認識・ハエ神経からの復号ではない。水平は軸ごとの線形和をtanh、上下は高度差・速度・気流・温度と交互作用の線形和をsigmoidに通す。重み13個は全て0から開始し、最初の状態は水平推進0、垂直推進50%。

高さ3.2 mからの誤差、追従誤差、推進二乗、速度、床近接、接触に罰則を設定。モデルは同じ `Lab.step` で評価し、学習版だけ別の物理を使わない。固定PDは評価時の比較対象のみで、学習モード内から呼ばない。温度14〜26°C、初期高度2〜4.5 m、プレイヤーから各水平軸±2 m、気流有無と強さ、ゆっくり動くプレイヤーを変える。人物はプレイヤー1人、壁なしで訓練した。

## 最終評価20場面の実測

| 指標 | 学習前 | 学習後 | 固定PD参考 |
|---|---:|---:|---:|
| 高度の平均絶対誤差 | 1.871 m | 0.114 m | 0.043 m |
| 水平距離の平均誤差 | 1.669 m | 0.155 m | 0.233 m |
| 開始3秒後以降の水平距離誤差 | 1.694 m | 0.066 m | 0.118 m |
| 床近傍にいたフレーム割合 | 43.4% | 0% | 0% |
| 接触回数の場面平均 | 0.65 | 0 | 0 |
| 労力の場面平均 | 4.500 | 4.198 | 3.851 |

保存した重みを読み直し、全20場面の結果一致を確認。事前の合格条件（損失が学習前の35%未満、高度誤差0.55 m未満、3秒後以降の水平誤差0.8 m未満、全場面接触0）を満たした。高度と労力は固定PDの方がよく、全指標で優れているわけではない。

## 適用範囲

UIに「学習した飛行［第1段階］」を追加し、読み込み成功時はこのモデルで飛ぶ。壁は初期状態で非表示にし、必要ならチェックで設置できる。壁回避は未学習。モデル未読込を学習済みとして扱わず、表示で知らせる。

ダッシュ、画面の温度全域、遠距離帰還、他モブの気流、長時間、視野外・遮蔽、画像入力は今回の合格判定に含まない。UIで試すことはできるが汎化成功とは未確認。より広い場面、長時間、柱1本の順に増やす。神経読み出し器の実験は `../brain-readout/` を参照。両者はまだ接続していない。
