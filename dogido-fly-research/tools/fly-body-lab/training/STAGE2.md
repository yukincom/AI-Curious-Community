# 第2段階: 柱1本の横回避とプレイヤーへの到達

第1段階の13係数を固定し、柱付近での水平操作に4係数の追加制御を学習した。ハエ回路とは未接続。画像から柱を認識する実験ではなく、世界が与える柱の形状から身体付近の幾何特徴を計算する。

## 実行と再現

```sh
node tools/fly-body-lab/training/train-stage2.mjs --output .fly-research/flight-training/stage2-new-run
node --test tools/fly-body-lab/sim.test.mjs tools/fly-body-lab/input-state.test.mjs tools/fly-body-lab/training/*.test.mjs
```

Node.jsのみ。保存した第1段階モデルと不採用の初回実験を入力にし、56場面・35世代・24候補・上位5候補のCEMで学習する。16場面でモデル選択し、その後に未使用32場面を24秒ずつ評価する。実行時間は約55秒。出力先を省略すると同梱の `run-stage2` を上書きするため、新しい実験では別の出力先を指定する。

## コードで決めた部分と学習した部分

- 第1段階の高度維持・目標への推進は固定。
- 柱の中心・寸法、身体の位置・速度、プレイヤー位置は世界側の情報。神経回路や画像の認識結果ではない。
- 身体の高さに重なる障害物について、衝突判定の拡張矩形を包む円までの余白が3.5m以内なら特徴を作る。近さ、目標への直線が塞がれる程度、柱へ近づく速度を使う。
- 柱から離れる向き・時計回りの接線・接近速度の制動・局所的な減速という特徴の形はコード設計。**学習したのは各特徴の強さ4個だけ**。回避経路を完全にゼロから発見したとは扱わない。
- 最終重みは `[0, 2.9599270525021124, 1.1863445953402623, 0.42435739245401305]`。直接押し返す係数は0となり、横へ回る操作と制動で通過した。手で係数を書き換えていない。
- 柱がなければ操作量は第1段階と完全一致。柱があっても上下操作の式は変えない。基準PDへの隠れた切替や学習後の衝突回避上書きはない。接触時の停止は全条件共通の物理。

## 一度失敗してからの再学習

初回は12場面で学習し、別12場面で選択。未使用32場面のうち30場面成功、2場面で接触し不採用にした。結果を `attempt-stage2-01/` に残している。初回の再現用入口は `train-stage2-attempt1.mjs`。

再学習では、初回の学習・選択・評価の**全56場面を練習データへ移した**。接触ペナルティを12から100に増やし、制動が加速に化けないよう係数を0〜12に制約。初回の選択モデルを非負へ制限した値から探索を再開した。新しい選択16場面・最終評価32場面はそれらとseedが重ならない。失敗した初回評価を未使用テストと呼び直していない。

## 新しい32場面の結果

柱の幅0.6〜1.3m・高さ6m、接近角度、開始距離2.8〜4m、初期高度2.8〜3.6m、温度14〜26°C、気流の有無・強さ、目標のゆっくりした横移動を変える。

| 指標 | 第1段階のまま | 第2段階 |
|---|---:|---:|
| 無接触で到達・追従した場面 | 10 / 32 | 32 / 32 |
| 接触回数の合計 | 22 | 0 |
| 最後5秒の水平距離・平均 | 0.469m | 0.059m |
| 高度の平均絶対誤差 | 0.093m | 0.082m |
| 水平移動距離・場面平均 | 9.106m | 10.550m |

停止して接触を避けるだけでは合格しない。全場面で無接触かつ最後5秒の平均距離0.6m未満、身体全体が柱の頂点より下、平均高度誤差0.3m未満、平均損失が学習前の半分未満、空室の結果が第1段階と完全一致、を判定した。最高高度は3.578m、半径0.25mを加えても6m未満。目標から0.6m以内への初到達は約3.2〜5.2秒。

保存モデルから32場面の全実測値を再現。NPCが散歩するUI用の配置でも24秒・接触0・目標へ到達を自動検証した。

## ラボで試す

「柱をよける飛行［第2段階］」を選び、「柱の向こうへ呼ぶ」を押す。人物・身体の位置と記録をリセットし、柱を挟んで向かい合う。現在は自動散歩が既定。止めて比較するなら「その場で待つ」、WASD／矢印キーで動かすなら「自分で動かす」を選ぶ。「学習した飛行［第1段階］」へ切り替えて同じボタンを押すと比較できる。室温・気流は現在の調整を保つ。

障害物は「なし／柱1本／低い壁」を選べる。低い壁、複数障害物、迷路、動く障害物、狭い通路、壁に接した目標、ダッシュ、温度の全域、長時間は今回の合格範囲外。手動プレイヤーの自由な動き全般について成功を保証しない。一定方向へ回る特徴なので、最短経路を保証するものでもない。

次は回避の見た目・速度を人が確認してから、目標の動きの拡大や柱の配置追加を行う。神経信号の読み取りは別実験のまま維持する。

実ブラウザでも、第1段階は柱へ接触して距離約3.75mで停止、第2段階は接触0・距離約0.02mへ到達することを確認。呼び寄せによる操作モード切替、短い矢印キー入力でのプレイヤー移動、コンソールエラーなしを確認した。
