# 第3段階: 動くプレイヤーと一緒に散歩する

第1段階の浮遊・第2段階の柱回避の係数を固定し、**現在のプレイヤー速度を何秒先まで延ばして追うか、1個の係数だけを学習**した。結果は約0.570秒。ハエ神経回路・画像認識・LLMとは未接続。

プレイヤーの自動散歩はコードで決めた経路に沿って歩く。ハエ君には未来の経路を入力せず、そのステップで人物が実際に移動した量と向きだけを使う。歩行が衝突で止まったときも、要求速度ではなく実移動速度を使う。相手が静止すれば第2段階と操作量が完全一致する。

## 再現

```sh
node tools/fly-body-lab/training/train-stage3.mjs --output .fly-research/flight-training/stage3-new-run
node --test tools/fly-body-lab/sim.test.mjs tools/fly-body-lab/input-state.test.mjs tools/fly-body-lab/training/*.test.mjs
```

第2段階の保存モデルを入力にし、先読み0秒から開始。CEM14世代・12候補・上位3候補で探索し、12場面（各40秒）で訓練、別8場面（各60秒）でモデル選択した。初回の実行時間は約10秒。先読みの式はコード設計で、入力は世界の人物位置と実移動速度。生物の予測機構を再現したという主張ではない。

最終評価は新しいseedの24場面・各120秒と、さらに別seedの600秒場面。柱の幅・位置、経路の向きと半径、時計／反時計回り、歩行速度0.5〜1.2m/s、14〜26°C、気流、NPC有無を変えた。同じ `Lab.step` と `GroundActors` を使い、学習のために人物を毎フレーム瞬間移動させない。

## 実測結果

| 指標 | 第2段階のまま | 第3段階 |
|---|---:|---:|
| 開始10秒後からの平均水平距離 | 0.539m | 0.231m |
| 接触した場面 | 0 / 24 | 0 / 24 |
| 平均高度誤差 | 0.064m | 0.067m |
| 人物の歩行距離・場面平均 | 79.53m | 79.53m |
| 推進二乗積分・場面平均 | 38.48 | 40.06 |

追従の遅れは減ったが、推進の総量は少し増えた。第2段階も今回の場面では無接触であり、衝突改善の実験とは扱わない。

各場面で接触0、開始10秒後以降の平均距離0.6m未満、距離1.5m超の割合1%未満、人物の実歩行20m超、柱上越えなし、全場面平均の高度誤差0.3m未満、追従距離20%以上改善を合格条件にした。

独立した10分場面でも接触0、平均距離0.148m、平均高度誤差0.060m、人物の実歩行319m。UI用の固定コースも10分間のシミュレーションで接触0・平均距離0.6m未満を検証した。保存モデルで全24場面と独立10分場面の結果を再現するテストを含め、関連25テストが通る。

## 画面の使い方

- 起動時は「一緒に散歩する飛行［第3段階］」「自動で散歩する」「柱1本」を選択済み。
- プレイヤーは柱の周囲の4地点を0.8m/sで歩き、各地点で少し休む。村人と他プレイヤーも従来どおり散歩する。
- 「柱の向こうへ呼ぶ」は配置を作り直すが、自動／手動／待機の選択を維持する。比較のため相手を止めたい場合は「その場で待つ」を選ぶ。
- 「最初から」でもプレイヤーの操作モードと散歩コースを維持する。手動操縦を明示選択したときはプレイヤーを待機させ、キー操作が二重に作用しない。

表示中は保存モデルで推論する。画面を開いているだけで学習係数を更新する仕組みではない。ブラウザが非表示になると描画・シミュレーションが止まる場合があり、実時間で常時稼働するバックグラウンド実験とは区別する。

複数の柱、迷路、動く障害物、極端な温度は未評価。通常の手動歩行2m/s・ダッシュ3.4m/sも今回の歩行速度範囲外。視界から相手を認識する学習ではなく、遮蔽中も世界側のプレイヤー情報を受け取る。

実ブラウザでも第3段階・自動散歩・柱1本の初期選択、呼び寄せ後とリセット後の自動モード維持、歩行と追従、接触0を確認した。これは10分間の実画面観察ではなく、上記10分評価はシミュレーションの自動検証。
