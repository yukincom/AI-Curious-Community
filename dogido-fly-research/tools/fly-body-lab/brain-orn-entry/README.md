# 嗅覚入口の監査と空腹／満腹の二値比較

## 結論

**外部の刺激生成はOFF直後に0になるが、実際のORN出力は一部で残る。** 空腹／満腹の各4試行、計8試行で、全2,635 ORN中の同じ10細胞がOFF19〜20秒にも発火した。最大201〜210 Hz。うち直接刺激したDM1の1細胞は30〜34 Hzで残る。PNだけの問題と切り分ける前提はまだ満たされない。

空腹／満腹を入力利得1.0／0.5として比較すると、刺激ORNのピークは変わるが、PNのピークとOFF後の高発火はほぼ変わらない。「状態で嗅覚が変わり、OFFで静まり、再刺激に応ずる」という全判定は0/4組。ALの接続・重みは変更していない。

最後の行は全ORNからPNへ送出する**シナプス増分の絶対値の総和／秒**を、同試行の刺激後半で割った値。シナプスの強さを反映した入口の量であり、PN膜で実際に有効だった電流やPN発火への因果寄与率ではない。固定伝達遅延のため送出と到着にも差がある。

元の集計は刺激した157 ORNの平均だった。約0.2 Hzという平均から「センサーが静まった」と結論しないこと。今回観測した全ORNの初期0.5秒は0発火であり、後半の10細胞の発火をもともとの自発活動と呼ぶ根拠もない。

## 空腹／満腹の比較

同じ人工餌匂いのON/OFFを与え、餌匂いを受けるDM1/VA2 ORNへの**外部Poisson駆動の利得だけ**を変えた。基準入力60 Hzに、空腹1.0／満腹0.5を掛ける。これは受容器利得の最小の工学的代理であり、学習結果でも実ハエの空腹利得の測定値でもない。シナプス重みやAL内の伝達利得、ORNへの全シナプス入力利得は変更していない。

| 初回ピーク50 ms | 135.36〜136.97 | 135.95〜136.73 |
| 刺激後半500 ms | 134.13〜135.72 | 134.12〜135.36 |
| OFF後1秒 | 133.08〜134.72 | 133.64〜134.66 |
| OFF後20秒 | 132.84〜135.01 | 133.43〜134.52 |
| 再刺激ピーク50 ms | 136.09〜137.00 | 135.28〜136.73 |
| 再OFF後1秒 | 133.28〜134.97 | 133.10〜134.42 |

再刺激の10 msピークを含む全値は `state-summary.csv` に保存。刺激ORNの初回50 msピークは空腹65.22〜69.68 Hz／満腹33.76〜37.07 Hzとなり、全4組で空腹の方が高い。一方、PNの初回ピークが両窓とも空腹で高いのは1/4組、全組の空腹／満腹比は約0.992〜1.008に留まる。入口に設定した状態差が、PNのピークの明瞭な差へ伝わっていない。

判定は実行前の `protocol.json` に固定。PNの初回ピークが両窓とも空腹で高いこと、両状態のOFF1秒・20秒・再OFF1秒が3 Hz以下であること、再刺激両ピークが各状態の初回ピークの70%以上かつ再刺激50 msピークが直前OFF20秒値を上回ることを確認した。**全条件を満たす組は0/4**。高いままの回路が再刺激中にも高いことを、静穏からの回復と扱わない。これは今回の強度・時刻・4seedでの工学的検査であり、全ての匂い・濃度・生理状態への保証ではない。

## ORN適応・最初のシナプス・OFF細胞の点検

| 項目 | 固定した現モデル | 一次研究で報告されていること |
|---|---|---|
| ORN自体の受容・適応 | 匂い分子→受容器のモデルなし。Poisson生成器がORNの `emitSpike` を直接呼ぶ。閾値適応は既定0で、生成器の発火判定自体は膜閾値や適応を見ない | 匂い変換とスパイク生成の二段階の動態、変換過程の適応がある。[Nagel & Wilson 2011](https://www.nature.com/articles/nn.2725) |
| ORN→次細胞の短期抑圧 | 上流固定版は一定の辺重みと共通のシナプス時定数。今回STDを追加していない | ORN→PNで短期抑圧がある。ただし単純な抑圧だけでは実PNの持続応答を過小評価する。速い／遅い伝達成分と動的なシナプス前抑制が重要。[Nagel, Hong & Wilson 2015](https://pmc.ncbi.nlm.nih.gov/articles/PMC4289142/) |
| OFFを符号にする応答 | OFF指定の細胞モデル、細胞固有の電位依存性反跳電流、負の匂い刺激を表す受容器モデルは未実装。配線から過渡応答が生じる可能性は別途実測 | 実ハエの抑制性LNにはON型、OFF型、両方に反応する型があり、OFF応答には興奮・抑制入力と内在性反跳が関係する。[Nagel & Wilson 2016](https://pubmed.ncbi.nlm.nih.gov/27076428/) |
| 空腹による感度変化 | 二値は実験用に外部から固定。食事・代謝・学習から更新しない | 特定ORNでsNPF・インスリンを介する空腹依存のシナプス前促通がある。今回のPoisson率の倍率と同じ仕組みを実装したわけではない。[Root et al. 2011](https://pubmed.ncbi.nlm.nih.gov/21458672/) |

生物の適応（刺激中の履歴依存の変化）と、今回の刺激OFF後の残留は別の測定対象である。文献は欠けている機構の候補を与えるが、それを足せば今回の残留が直ると証明したものではない。

OFF候補は全ORN・ALPN・ALLNの計3,741細胞を探索。OFF直後200 ms内の50 msピークが刺激後半より20 Hz以上かつ2倍以上高く、OFF1秒ではピークの半分以下、初回OFF20秒では3 Hz以下となることを両パルスで要求した。事前固定したこの探索基準では、空腹seed2026091731だけで2細胞が候補となったが、どちらも各OFFに50 ms内1スパイク相当の20 Hzで、4seedを通して再現する候補は0。これは「生体やモデル内にOFF応答が一切ない」という証明ではない。継続ON対照や機能的な細胞同定は未実施。詳細は `OFF-candidates.json`。

## 残る10細胞への入力と次の焦点

`active-ORN-incoming.csv` に元データの全入力辺を保存。例えば最大発火の `ORN_DL1`（bodyId 153948）には、正のALPNから213 contacts、正のALLNから74 contactsなどがある。刺激DM1（222974）にも正のALLNから60、ALPNから10 contactsがある。これは構造の観測であり、その辺が今回どれだけ発火を生んだかの測定ではない。

現在のLIFは各細胞に一つの膜電位とシナプス変数を持ち、ORNも同じ積分則で再発火する。ORN終末へのシナプス調節と、感覚細胞体・受容部の興奮性を区画で分けていない。この表現と実際の終末調節の違いは、残留の原因候補になる。ただし、今の監査だけではどの入力・どの生理の省略が原因かは断定できない。

次はこの10個のORNで、OFF中に到来する入力と発火の関係を測ることが具体的な焦点になる。センサー側の残留が整理される前にAL内の切断を重ねない。今回の知見は「外部駆動は停止／一部ORNの実出力は持続／PNも持続」までであり、ハエ特有の内部ループが原因と確定したわけではない。ORN適応・ORN→PN抑圧・OFF回路の導入とライブラボへの反映は、今回の監査には含めていない。
