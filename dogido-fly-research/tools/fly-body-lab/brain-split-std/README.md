# PN→eLN と eLN→eLN の短期抑圧を分ける比較

同じ固定ハエ回路で、抑圧なし、PN→eLNだけ、eLN→eLNだけの3条件を各4試行。前回の一括条件から送信元クラスだけを分けた独立研究。稼働中のラボとDogido本体は変更しない。

## 結果: 単独で採用できる条件は0件

[全指標・判定・図](results/RESULTS.md) · [試行ごとの数値](results/PN-summary.csv)

両介入とも4/4試行で初回・再刺激ピークの70%基準と刺激後半の基準を通過した。一方、OFF1秒・OFF20秒・再OFF1秒は全て0/4試行。指定の必須条件が揃わないため、どちらも本番へ採用しない。

| 単独の抑圧 | 初回ピーク50 ms / 対照 | 刺激後半 / 対照 | OFF20秒のPN | 再OFF1秒のPN |
|---|---:|---:|---:|---:|
| PN→eLN | 92.4〜93.6% | 91.8〜92.8% | 123.41〜124.24 Hz | 123.40〜124.36 Hz |
| eLN→eLN | 79.5〜80.1% | 72.5〜74.0% | 98.40〜99.04 Hz | 98.22〜99.45 Hz |

再刺激の数値上のピークは残るが、直前も高発火のままである。「静まってから再び応答する」回復は成立していない。3 Hzを5 Hzに変えても結論は変わらず、30%の刺激後半基準を50%に上げても両介入はそこを通る。失敗は曖昧な閾値の境界によるものではない。

## 接続の役割と次の切り分け

- **PN→eLNは「残留の支え」の一部という候補**。弱めると残留も下がるが約123〜124 Hzに留まる。刺激後半も同程度の割合で下がり、この経路だけを弱めても停止は起こらない。
- **eLN→eLNも「残留の支え」の一部という候補で、抑圧すると「刺激中を削る部品」としての作用も大きい**。残留は約98〜99 Hzまで下がる一方、刺激後半も対照の約73%に下がる。OFFだけを選んで止める機構とは判定できない。
- この2分類は排他的ではない。接続は本来興奮性であり、「刺激中を削る」のはそこへ今回加えた抑圧の効果を指す。集団単位で弱めた比較なので、個々の辺の必要性や生体の役割まで確定したわけではない。

[前回のPN/LN→eLN一括300 ms](../brain-internal-std/README.md)ではOFF20秒が3/4試行で0近傍に下がった一方、刺激後半が大きく失われた。今回の片方ずつではいずれも残留が維持された。**「どちらか片方の単独抑圧だけ残す」という候補選別は、今回は該当なし**。
両経路を同時に弱めたときの作用、未抑圧の経路による活動維持、回路の非線形な閾値などを次に区別する必要がある。これだけで単一の原因接続は指定できない。次の切り分けでは、同時に弱めたときにどのPN/eLN集団の持続発火が先に崩れるかを候補にし、今回と同じ必須条件で採否を見る。追加の条件・切断・本番への反映は今回実行していない。

## 実験を先に固定

- 元コード: `blendi-remade/fly-brain-minecraft` の `6cfa30175003ef25da68a237d5eda958f8047b82`。接続データと元Java 4ファイルの内容を検証してからビルド。
- 対象は正の伝達符号を持つ `ALLN` 192細胞（モデル上のeLN）。ACh 144、unclear 46、octopamine 2を含む。生体で全て興奮性だと確認したという意味ではない。
- PN→eLN: 正の `ALPN` 401送信元、9,895辺、262,476 contacts。eLN→eLN: 正の `ALLN` 179送信元、6,008辺、315,738 contacts。読み出すPNは `ALPN` 全686細胞。
- 抑圧は U=0.2、資源回復時定数 τ=300 ms。300 msだけ抑えるタイマーではない。初回伝達は元のまま、発火後に資源を0.8倍し、発火間に指数回復する。選択された辺は送信元ごとに同じ発火履歴・同じパラメータなので資源変数を共有できる。
- ORN入力・非選択送信元・eLN以外への出力・抑制性伝達は変更しない。膜リーク、不応期、閾値、適応項、gainも前回のまま。OFF時の強制リセットはない。
- 刺激はDM1/VA2 ORN 157細胞への60 Hz Poisson駆動。dt=0.5 ms、gain=0.65、KC gain=0.25、各試行1スレッド。seedは2026091701 / 2026091711 / 2026091721 / 2026091731で条件間を対応させる。
- 時間割: 無刺激0.5秒 → 刺激1秒 → OFF20秒 → 再刺激1秒 → 再OFF2秒。全24.5秒はシミュレーション時間。
- `results/protocol.json` を最初の実行前に保存。条件や閾値の事後調整なし。

## 指標と採用候補の判定

指定順にPN集団の平均発火率を測る。全てHz / neuron。

1. 初回刺激中ピーク: 刺激内に全体が収まる10 ms・50 msの移動平均の最大。1 ms刻み。
2. 刺激後半: 最後の500 msの平均。
3. OFF後1秒: OFF +900～1000 msの平均。
4. OFF後20秒: OFF +19900～20000 msの平均。
5. 再刺激ピーク: 初回と同じ10 ms・50 ms窓。
6. 再OFF後1秒: 再OFF +900～1000 msの平均。

ピークは同seed・同じ刺激回の対照に対して両窓とも70%以上（ユーザー指定の70%を両窓・両刺激回に適用）。再刺激の50 msピークが直前のOFF20秒値を超えることも確認する。
刺激後半は対照の30%以上、OFF1秒・20秒・再OFF1秒は各3 Hz以下とする。**30%と3 Hzは実行前に明記した暫定の工学的判定値**であり、生理学的基準ではない。
全7項目を4試行全てで満たした介入だけを採用候補とする。対照の高活動そのものを正常な生体応答と見なさない。

## 再現と検証

研究worktreeのルートで実行する。必要: JDK 25、Python 3、NumPy、Matplotlib。以下の出力先は未作成のものを指定する。

```sh
LAB=tools/fly-body-lab/brain-split-std
UPSTREAM=.fly-research/upstream/blendi-remade--fly-brain-minecraft
JDK=/path/to/jdk/bin
python3 "$LAB/build.py" --upstream "$UPSTREAM" --output /tmp/fly-split-build-new --jdk "$JDK"
python3 "$LAB/run.py" --build /tmp/fly-split-build-new --data "$UPSTREAM/src/main/resources/connectome/malecns-v1.0.flyb.gz" --java "$JDK/java" --previous tools/fly-body-lab/brain-internal-std/results --out /tmp/fly-split-results-new
python3 "$LAB/analyze.py" /tmp/fly-split-results-new
python3 "$LAB/validate_metrics.py" /tmp/fly-split-results-new
python3 "$LAB/plot.py" /tmp/fly-split-results-new
python3 "$LAB/summarize.py" /tmp/fly-split-results-new
```

- 両経路の資源回復を解析式と照合。繰り返しORN入力、選択外PNへの出力、抑制性入力が元の振幅であることを検査。
- 全176,422細胞に対して、実際に選択された送信元がクラス・符号・接続先による期待集合と完全一致することを検査。
- 無刺激3条件は3.5秒を観測し、スパイクと伝達が全て0。
- 対照4試行の全24.5秒・全観測集団の1 msスパイク数を前回の実測と完全照合。
- 1 ms記録の全時刻順序・刺激時間割・スパイク数を検査。膜電位の有限性、伝達の上限とORN伝達不変は50 msごとに検査。
- 集計とは別のNumPy畳み込み・配列切り出しで指定全指標と判定を再計算する。

生データは `results/*-spikes.csv`（1 ms）、`*-synapses.csv`（50 ms）。`report.json` はPN、eLN、ACh-eLN、unclear-eLN、GABA-LN、刺激ORNの詳細、`PN-summary.csv` は指定順の一覧。チェック結果、固定プロトコル、ビルドメタデータ、最小パッチも保存する。
