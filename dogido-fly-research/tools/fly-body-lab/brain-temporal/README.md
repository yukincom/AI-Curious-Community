# 継続刺激と残留活動の読出し実験 / 01

固定ハエ回路の匂い刺激を除去した後も続く活動について、直近の活動履歴から「刺激中」と「刺激なし」を読み分けられるか調べる独立実験。既存のブラウザラボ・飛行制御・神経回路の重みは変更しない。読む側の係数だけを学習する。

## 結果：改善したがライブには不採用

2026-09-16、実回路の生成に247.49秒。非有限な膜状態0。学習1,200窓、別seed・強度・時間割での評価1,200窓。

| 読み取り方式 | 刺激中を正しく検出（252窓） | 刺激除去後を正しく判定（460窓） | クラス別再現率の平均 |
|---|---:|---:|---:|
| 旧固定読出し器 | 246 / 252（97.6%） | 41 / 460（8.9%） | 76.7% |
| 今回の現在値8特徴 | 241 / 252（95.6%） | 59 / 460（12.8%） | 76.7% |
| 今回の履歴24特徴 | 251 / 252（99.6%） | 209 / 460（45.4%） | 86.6% |

3方式とも刺激前・無刺激対照の488窓は全て正判定。時間履歴の学習損失は0.6931→0.3026へ減少し、4評価seedごとのクラス別再現率平均は85.5〜87.6%。全体正解率は79.0%で、「常に刺激なし」と答えるだけの比較も79.0%になる。このため全体正解率だけを成功の根拠にせず、刺激中と除去後を分けて評価した。

**履歴を加える効果は見えたが、刺激除去後も251 / 460窓を誤判定した。** 事前に決めた5条件のうち、クラス別再現率平均90%と除去後正判定90%の2条件を満たさず不採用。現在のライブ読出し器・画面・神経の重み・身体センサーによる寄り道停止条件は変更していない。

[評価レポート](results/report.json)、[全評価窓の予測](results/heldout-predictions.json)、[履歴モデル](results/temporal-model.json)、[現在値モデル](results/current_only-model.json)、[実測CSV](results/dataset.csv)。これらは実験成果物であり、ライブ用モデルの代替として自動読込しない。

今回の失敗は「神経活動から刺激除去を読めない」と一般化できない。調べたのは、固定された8集団平均と250 msの履歴を線形に読む方式だけ。次の候補は、個別の下流集団やより長い活動履歴の検証。今回の評価データを見て方式を調整する場合、このデータは開発用へ移し、採否は新しい未使用seedとスケジュールで測る。

## 方法

[事前固定した条件](protocol.json)と[生成条件](results/dataset-metadata.json)。上流4クラスは未改変のまま、コミットとデータSHA256を照合してコンパイル。176,422ニューロン、6,287,749接続、dt=0.5 ms、gain=0.65、KC入力gain=0.25、1 worker。刺激が切り替わっても神経状態をリセットしない。

- 24試行×神経内5秒＝2,400個の50 ms窓。各試行開始時のみ新しい回路を作る。
- 各seedにつき、静か→刺激→除去→再刺激→除去の2系列と、最初から最後まで無刺激の対照1系列。
- 学習seedは2026091701〜1704、評価seedは1705〜1708。以前の読出し試験のseedも使わない。
- 学習の刺激60/120/180 Hzに対し、評価は90/150 Hz。切り替え時間も異なる。刺激除去後は最長2秒を観察する。
- 入力ニューロンORN_DM1/ORN_VA2に直接刺激し、それと重ならない8つの下流集団を測る。世界側の匂いセンサー値を発火率として代入しない。

**学習特徴は神経活動だけ。** 8集団の現在のlog1p発火率、1窓前との差、直前4窓の平均との差の24個。試行開始時は履歴を0で埋め、試行間で状態を持ち越さない。未来窓、時刻、seed、試行名、刺激強度、phase、正解ラベル、身体センサーは特徴にしない。

比較用に、同じ学習データから現在の8活動だけを読む分類器も学習する。双方とも2値ロジスティック回帰、ゼロ初期値、800更新、学習率0.08、L2=0.002、クラス重み付き損失、判定閾値0.5。標準化は学習側だけ。旧固定読出し器も、ライブ接続と同じodor確率0.65以上を刺激ありとする比較に使う。

評価結果を見たハイパーパラメータ調整は行わない。採用には、評価balanced accuracy・刺激中再現率・除去後の正判定が各90%以上、現在値だけの方式へのbalanced accuracy改善が2ポイント以上、旧方式への除去後正判定の改善が20ポイント以上を全て要求する。これは今回の工学的な採用条件で、一般的な科学的基準ではない。

## 再実行

JDK 25とPython 3標準ライブラリ。既存のラボや成果物を上書きしない別の出力先を指定する。研究リポジトリのルートから:

```sh
python3 tools/fly-body-lab/brain-temporal/generate_temporal.py \
  --upstream .fly-research/upstream/blendi-remade--fly-brain-minecraft \
  --output .fly-research/temporal/new-run
python3 tools/fly-body-lab/brain-temporal/train_temporal.py \
  .fly-research/temporal/new-run/dataset.csv \
  --original-model tools/fly-body-lab/brain-readout/results/model.json \
  --output .fly-research/temporal/new-run
cd tools/fly-body-lab/brain-temporal
python3 -B -m unittest test_temporal -v
```

生成器は600秒で打ち切り、非有限な神経状態や条件不一致なら失敗にする。生成されたJavaクラスは同梱しない。保存重みから全評価予測の再現、未来・メタデータの非使用、試行間リセット、不正な入力、学習更新をテストする。

## 解釈の範囲

1つの50 ms窓を独立実験とは数えない。評価seedは4個で、それぞれが同じ2種類の評価スケジュールを共有する。人工的な匂い刺激だけの2分類であり、接近・視覚・温度などの識別性能を示さない。無刺激対照を含む全体正解率だけで、刺激除去への応答が改善したとは判断しない。
