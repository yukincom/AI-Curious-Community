# 膜リーク・抑制・適応の切り分け（2026-09-17）

固定版の回路を使った小試験。元のJavaソース・データは変更せず、一時プロセス内の接続重みをゼロにして、単一神経または一本の接続を観察した。実行中のラボには変更なし。全脳の60秒残留の原因を確定した試験ではない。

## 実測

- **膜リークは動作した。** 接続を全て無効にした神経を閾値未満の−46 mVに置くと、20 ms後は−49.792720795 mV。時定数20 msの理論値−49.792723353 mVと一致（誤差約0.000003 mV）。200 ms後は休止値−52 mV。最後は既存のidle閾値で休止値に丸められる。
- **GABAの負の接続は動作した。** ALLN body ID 23854からALPN 13389への594シナプスの一本の接続だけを残し、入力側に一発の発火を起こすと、10 ms後の相手は−68.578674 mVまで過分極した。これは強い接続一件の符号・配線試験で、実際のGABA受容体の定量的再現やネットワーク全体の抑制の十分さは証明しない。
- **適応は既定で無効。** `adaptIncMv=0`。孤立神経へ1 mV/msの一定入力を1秒与えると100発。比較用に一発ごとの閾値上昇1 mV、回復時定数100 msを設定すると54発になった。任意の機能確認用設定であり、生物に合わせた校正値でも、本番へ採用した値でもない。
- 読み込んだALLN 420個の伝達物質と符号は、acetylcholine +1:144、gaba −1:120、glutamate −1:108、octopamine +1:2、unclear +1:46。LN全体をGABA抑制性と見なさない。未確定の46個が興奮性へ割り当てられる点も仮定として残る。

[測定値](results/results.tsv)・[固定版とハッシュ](results/metadata.json)。ラッパー内の数値条件を満たさなければ実行は失敗する。

## 解釈と次の比較

「膜リークが消えている」「GABA抑制が全くない」は、この限定試験では支持されない。一方、単体のリークや抑制が正常でも、再帰的興奮との釣り合いが崩れれば持続活動は起こり得る。適応の無効化、抑制性細胞の実際の活動量、符号不確定の接続、前回確認した不応期中の入力蓄積を別々に評価する必要がある。

実ハエのGABA作用は単純な負の重みだけではない。[Olsen & Wilson (2008)](https://pmc.ncbi.nlm.nih.gov/articles/PMC2824883/)は、ORN末端でのGABA_A/GABA_Bによるシナプス前抑制を報告する。現在のモデルは全ての速い入力を同じgへ足し合わせ、受容体別の動態・反転電位・伝達効率の調節を表現していない。[Shiuらの本家論文](https://www.nature.com/articles/s41586-024-07763-9)も、同一LIF神経・受容体動態などを省いたモデルの適用範囲を明示している。正規の研究モデルは既に存在するが、ゲームへの派生版がその全ての検証を継承するわけではない。

優先するのは、不応期の実装差を小回路で照合すること。その上で全脳ではGABA系LN・興奮性LN・PNの活動を同時に測り、一つずつ条件を変える。「止まる値に調整した」だけで生理の再現としない。

## 視覚についての確認

今回および前回の匂いOFF試験は視覚入力なし。ラボの`sim.mjs`には位置・向き・遮蔽物から求める簡易な`visible`リストがあるが、`neural-client.mjs`から`LiveBrainWorker.java`へ渡る神経刺激は匂いの強度だけ。画像・網膜入力・匂い源の視覚的消失・摂食イベントは、このライブ接続にはない。別の独立試験でLC4/LPLC2への接近刺激を与えたことはあるが、物体認識や食物消失の試験ではない。

視覚経路を接続した後は、匂いあり/なし × 匂い源が見える/見えないの4条件を、同じ刺激前履歴で比較する価値がある。物体が見えなくなること、食べられた事実、その出来事と匂いを対応づけることは別々の能力。視覚OFFを直接神経リセットへ結んだ場合は、視覚による自然な抑制の証拠にならない。この比較は未実施。
