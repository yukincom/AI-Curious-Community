# eLN→PN停止後に残ったPNの到来入力監査

**残余PNへの正入力の75.72〜77.66%は、接続データで `thermosensory` と記されたTRN由来だった。PN由来は15.73〜16.42%。glutamateのiLN入力も届くが、このモデルでは負入力である。**

前回の保存済み8試行を再集計した。新しいシミュレーション、切断、パラメータ変更はない。到来入力の所在が分かった段階であり、TRN経路の必要性やTRNが発火を続ける原因は未検証。

## 入口・出力・残余を並べる

| 観測点 | 実施した確認 | 分かったこと | 残る境界 |
|---|---|---|---|
| 入口の10 ORN | [PN／LN→ORNの116辺をOFF到来だけ停止](../brain-orn-necessity/README.md) | 8試行で9細胞が静まり、153948は19〜20 Hz残った。PN平均は132〜135 Hzで変化1%未満 | 116辺の集合は9 ORNの再発火に必要だが、PN集団の高活動の必要条件ではない。残ったALIN→ORNの2辺は追加停止しない |
| eLN→PN出力 | [高活動PNの到来監査後、正符号eLN→PNをOFF到来だけ停止](../brain-pn-output/README.md) | PN平均は132.84〜135.01から3.66〜3.89 Hzへ約97%低下。既知正符号だけでは11.69〜11.94 Hz、unclearだけでは104.74〜106.01 Hz | 元回路からの独立試験で、前のORN停止は重ねていない。集団平均の低下は全PNの沈黙ではない |
| 今回の残余PN | 同じeLN→PN停止試行で、残ったPNへのOFF19〜20秒の実到来を再集計 | 正入力はTRN由来が約76〜78%、PN由来が約16%。最大個別発火は300〜330 Hzのまま | 到来量は発火の因果的寄与率ではない。今回は新しい必要性・十分性の試験をしていない |

この3点は、同じ回路に3回連続で切断を重ねた結果ではない。入口の介入、元回路から独立した出力の介入、その出力介入後の観察を並べたもの。

## 「残った25細胞」の定義と時間窓

前回報告の25〜27細胞は、各試行の**OFF19.9〜20.0秒の100 msに1回以上発火したPN**。今回はこの選択をそのまま使い、そのPNへ**OFF19〜20秒の1秒間**に届いた入力を調べた。

- 試行ごとの対象数は25〜27。8試行の共通部分は25個体、和集合は27個体。
- 入力観測と同じ1秒間で発火の有無を数えると27〜29細胞になる。これは前回の25〜27という数と窓が違うためで、以前の報告を1秒窓の細胞数へすり替えない。
- 1秒窓でだけ追加される個体IDと数は `summary.json` に保存した。今回の入力集計は前回の対象に限定する。
- 共通25細胞だけでも再集計し、thermosensory由来の割合は**77.31〜77.74%**。試行ごとに加わる2個体だけが主結果を作っているわけではない。
- 各8試行は以前と同じ4seed×入力利得1.0／0.5。`hungry` / `satiated` は再現ラベルで、新しい空腹生理の解釈は足さない。

## 実際に通過して届いた入力

各値は8試行の範囲。分母は各試行の対象25〜27 PNへ1秒間に届いた**正のシナプス増分総和**。負入力はその同じ分母に対する絶対量として別表にする。増分はモデルのシナプス状態 `g` に入る値であり、膜電位への寄与や発火の原因の割合ではない。

| 正入力の送り元 | 正入力に占める割合 |
|---|---:|
| thermosensory表記のTRN（ACh） | 75.72〜77.66% |
| PN（ACh） | 15.73〜16.42% |
| hygrosensory表記の細胞（ACh） | 2.97〜3.07% |
| class空欄の細胞（ACh） | 2.52〜4.68% |
| ALON（ACh） | 0.352〜0.375% |
| class空欄の細胞（octopamine） | 0.133〜0.153% |
| ALIN（ACh） | 0.113〜0.117% |
| DAN（dopamine） | 0.002〜0.004% |
| 正符号eLN、固定10 ORN、そのほかのORN | 0% |

| 負入力の送り元 | 絶対量／正入力総量 |
|---|---:|
| iLN（GABA） | 5.66〜6.38% |
| **iLN（glutamate）** | **2.70〜2.72%** |
| ALIN（GABA） | 1.46〜1.53% |
| class空欄（GABA） | 0.72〜1.56% |
| class空欄（glutamate） | 0.286〜0.317% |
| PN（glutamate） | 0.059〜0.065% |

glutamateのiLNが入力していることは確認できたが、この固定モデルでは負符号なので、これを正の駆動として説明しない。負入力がどの程度発火を抑えているかの個別介入も行っていない。モデルの伝達物質表記と符号を維持した集計であり、生体の全glutamate細胞の作用へ一般化しない。

以前の入力監査で「その他」にまとめられた項目の大部分が、この残余ではthermosensory表記のTRNだった。`thermosensory` / `hygrosensory` は接続データのclass名である。**外部から温度・湿度刺激を加えたという意味ではない。** この試験の外部刺激は以前からのDM1／VA2 ORN刺激で、今回調べたOFF窓の外部入力記録は0 Hz。TRNへ何が入力して発火させているか、TRN自身の持続か、別の戻り経路かは今回の観測範囲外。

## 残余にも入力の違いがある

正入力総量の上位3送信元は、8試行すべてで `TRN_VP3a` の **37147・35634・436612**。この3個体で対象PNへの正入力の **71.07〜73.09%** を占めた。これは観測した送信元の記録であり、次の切断対象を決めるリストではない。

| 残留PNの例 | OFF20秒の個別発火 | その細胞への正入力の特徴 |
|---|---:|---|
| 524990 / VP3+_l2PN | 300〜330 Hz | TRN由来96.36〜96.47% |
| 14666 / VP3+_l2PN | 270〜320 Hz | TRN由来95.88〜95.98% |
| 555966 / VP3+_l2PN | 260〜270 Hz | TRN由来92.65〜92.83% |
| 12965 / M_l2PN10t19 | 190〜200 Hz | PN由来87.08〜87.34% |
| 13981 / M_l2PN10t19 | 190〜200 Hz | PN由来86.88〜87.19% |

VPで始まる型名のPNは各試行16細胞で、残ったOFF20秒の全PNスパイク数の **73.96〜75.88%** を占める。従来のPN平均の分母は `ALPN` class全686細胞であり、DM1／VA2に限定した出力平均ではない。型名での集計を、生物学的な嗅覚／温度機能の確定へ置き換えない。

PN→PNの到来も記録している。大部分は同じ残留集合に属する別PNからで、自己入力の到来はなかった。少量は最後の100 msには発火していないPNから1秒窓内に到来する。これだけでPN同士の自己持続ループが成立したとはいえない。送信元の駆動を別経路から受けている可能性は残る。

**集団平均3.66〜3.89 Hzは、約3.7 Hzで全PNが弱く打っている状態ではない。少数の高発火PNと、多数のその100 ms窓で無発火のPNを平均した値である。** この注記を維持する。

## 再構成と検証

- 元データは `fca1970` の `brain-pn-output/results`。対象ファイルは親フォルダの `MANIFEST.sha256` と照合し、使用ファイルのハッシュを `input-sha256.json` に保存。
- 対象PNへ届く各辺のOFF19〜20秒の件数を、送信元の実スパイク数・既定の遅延から照合。停止件数が正符号ALLNだけと一致し、その通過は0であることを確認。
- 「到来件数−停止件数」×元のfloat辺増分から、対象PNごとの全16由来グループを別に再構成。保存済みの実到来集計との差は全8試行で0。
- 対象PNのOFF20秒の発火数総和が全686 PNの同じ窓の総和と一致し、集団カウンタから独立にも同じ数値になることを確認。
- 同じ解析を別の出力先でも実行し、すべての数値出力がバイト単位で一致。シミュレーションの再実行はしていない。
- 共通25細胞、全27個体の個別表、実際に通過した辺、送信元、class・伝達物質・符号別の表を保存。生データを複製せず、元データの参照とハッシュを保持する。

`delivered-edges.csv` は対象へ実際に通過した辺の記録、`sources.csv` は送信元別、`classes.csv` はclass・伝達物質・符号別、`cells.csv` は各試行の対象PN別。`common25.json` は共通部分だけの照合、`top-senders.json` は正入力の送信元上位3個体の観測。強い入力がそのPNの発火に必要だという断言には使わない。

## 再現

Python 3、NumPy、Matplotlib。研究ワークツリーのルートから、未作成の出力先を指定する。

```sh
LAB=tools/fly-body-lab/brain-pn-residual
PREVIOUS=tools/fly-body-lab/brain-pn-output/results
OUT=/tmp/pn-residual-results-new
python3 "$LAB/analyze.py" --previous "$PREVIOUS" --out "$OUT"
python3 "$LAB/summarize.py" "$OUT"
python3 "$LAB/verify.py" "$OUT"
python3 "$LAB/plot.py" "$OUT"
```

これは既存試験の残余監査。ALIN→ORNを含め、新しい切断やライブ回路への変更は行っていない。
