# DM1／VA2とVP3系PNのOFF20秒集計を分ける

**eLNの正入力をOFF中だけ止めた保存試行では、DM1／VA2を型名で明示する4 PNは全8試行で0 Hz。VP3を含む型名の14 PNは平均114.29〜120.00 Hzだった。**

既知の正符号eLNだけを止めた条件でも、同じ4 PNは全8試行で0 Hz。最後の100 msだけでなくOFF19〜20秒の1秒窓でも同じ4細胞の発火は0だった。以前の全686 ALPN平均3.66〜3.89 Hzを、この4 PNの嗅覚応答が残った証拠として扱わない。

同じ保存済み40試行を集計し直した。新しい切断・シミュレーション・TRNへの入力監査・温度チャネルの嗅覚への組み入れはない。

## 固定した細胞集合

発火率や停止後に残ったかどうかで選ばず、保存されたALPN class全686細胞の型名から固定した。静かな細胞も各集団の分母に含める。

- **DM1／VA2：4細胞**。型名の最初の `_` より前がDM1またはVA2のもの。DM1_lPNは10176・10208、VA2_adPNは10390・10561。各型2細胞。
- **VP3系：14細胞**。型名の最初の `_` より前を `+` で区切り、VP3という要素を含むもの。VP3+_l2PNだけでなくVP1l+VP3、VP3+VP1l、VP5+VP3の複合型も含める。今回の結果を見て複合型を除外しない。
- **その他：668細胞**。上記2集合のどちらにも属さないALPN。全体の残留を説明する際に省略しない。

全IDと型名は `cohorts.json`。40試行で集合と型名が一致することを確認した。前回の「残留PNのうちVPで始まる型名16細胞」と、今回の「静かな細胞も含むVP3系14細胞」は定義が異なる。

固定した集合の確認として、前回の接続メタデータも照合した。4嗅覚PNにはそれぞれ71〜76辺のDM1／VA2 ORNからの直接接続があり、thermosensory classからの直接辺は0。14 VP3系PNではDM1／VA2 ORNからの直接辺が0、thermosensory classからは各3〜7辺ある。これは型名との構造的一致の確認で、到来強度から新しい細胞集合を選んだものではない。

この4細胞はDM1／VA2を型名で明示するPN集合であり、DM1／VA2に間接的に関係する全細胞や全嗅覚PNを網羅すると主張しない。無名・多糸球体型などの機能を型名だけで確定せず、「その他」に保持する。

## 同じ試行のOFF20秒平均

各欄は同じ4seed×入力利得1.0／0.5の8試行の範囲。前回と同じOFF19.9〜20.0秒の100 ms窓で、**それぞれの集合内の平均Hz**を比較する。ON到来はすべて通す既存試行で、前のPN／LN→ORN停止は重ねていない。

| OFF到来の停止条件 | DM1／VA2（4 PN） | VP3系（14 PN） |
|---|---:|---:|
| 停止なし | 335.00〜352.50 Hz | 230.71〜239.29 Hz |
| 既知の正符号eLNだけ停止 | **0.00 Hz（8/8）** | 128.57〜134.29 Hz |
| unclearだけ停止 | 275.00〜295.00 Hz | 217.86〜226.43 Hz |
| 正符号eLN全部停止 | **0.00 Hz（8/8）** | 114.29〜120.00 Hz |
| GABAだけ停止 | 422.50〜427.50 Hz | 260.00〜264.29 Hz |

4細胞の平均だけが偶然0なのではなく、4個体それぞれ無発火。DM1の2細胞、VA2の2細胞を別々に集計しても両停止条件で0。OFF19〜20秒の1秒窓でも同じ結果であり、短い観測窓の端だけを拾った0ではない。

**この4 PNのOFF20秒静穏という観点では、unclearを追加停止しなくても、既知の正符号eLN停止条件で達していた。** 全ALPN平均だけを見て追加停止の必要性を判断しない。ただしONや再刺激を含む実装上の採否を、このOFF20秒だけでは決めない。

## 約3.7 Hzを分解する

正符号eLN全部停止条件で、各集団の発火数を**共通の686細胞で割った寄与**を示す。上の表の集合内平均とは分母が違う。

| 集合 | 全686 PN平均への寄与 |
|---|---:|
| DM1／VA2の4 PN | 0 Hz |
| VP3系14 PN | 2.33〜2.45 Hz |
| その他668 PN | 1.33〜1.46 Hz |
| 全686 PN | 3.66〜3.89 Hz |

各試行で3集合の寄与を足すと元の全PN平均に完全一致する。表の各範囲の上下限は異なる試行で生じるため、範囲の端同士を足して一致を要求しない。

**集団平均低下は全PNの沈黙ではないという注記を維持する。** [前回の残余監査](../brain-pn-residual/README.md)で25〜27細胞が最後の100 msに打ち、個別最大300〜330 Hzだった事実は変わらない。今回分かったのは、指定したDM1／VA2の4 PNはその残留に含まれず、VP3系を含む別のPNの活動が同じ平均に入っていたこと。

一方、「その他」にも発火が残る。その全細胞を別感覚または温度と分類したわけではなく、3.7 Hzの全量を温度活動と呼ばない。TRNの入力源や持続機構を調べる前に、匂いチャネルの評価を分ける根拠が得られた段階である。

## ドギドへの実装判断

現時点は**指定した嗅覚PNのOFF20秒静穏を確認済み、本番採用の判定はまだ保留**。

今回の対象は元のLIF回路そのものの完成度を網羅的に証明することではなく、ドギドに使う指定嗅覚チャネルが必要な時間応答を返すかである。評価の分母を全ALPNから指定PNへ分離することは、そのための基礎として扱う。

| 確認項目 | 今回の到達点 |
|---|---|
| 匂いチャネルとVP3系を分けて測る | 保存40試行で完了。対象ID・分母を固定 |
| OFF20秒で指定した嗅覚PNが静まる | 既知正符号／全正符号eLNのOFF停止条件で4 PNすべて0、各8試行 |
| 刺激中ピークを保つ、後半が極端に死なない | 同じ4 PNの時間別指標としては今回未判定 |
| OFF1秒で落ちる、再刺激で上がり再OFFで落ちる | 同じ4 PNの時間別指標としては今回未判定 |
| 身体の入力と匂い検知信号として往復する | この選択PN・停止条件を使ったライブ接続は未実装・未確認 |

次の実装判断に必要なのは、同じ4 PNで以前合意した時間応答条件（ピークは対照の7割以上、刺激後半の応答、OFF1秒・OFF20秒、再刺激と再OFF）を確かめ、採用する読み出しと身体由来の匂い検知信号を照合すること。TRNへの新しい切断や温度チャネルの嗅覚への追加を、その前提にしない。

今回の個別PN保存値は20.5、21.4、21.5、24.5秒の累積発火であり、最初のONピークや再ONと再OFFを別々には復元できない。集団カウンタ全686 PNの時間履歴を、指定4 PNの時間応答として代用しない。必要な短い時間記録の追加は、次の確認として分ける。

研究用の試験接続に進める段階と、本番へ採用できる段階を分けて報告する。今回の0 Hzだけで「ドギドに実装して大丈夫」とは判定しない。

## 検証と再現

元データは `brain-pn-output/results`（作成commit `fca1970`）、今回の回復点は `79038ce`。保存ファイルを親のMANIFESTと照合し、入力ハッシュを保持した。

- 型名の定義で集合を固定し、40試行で全686 ID・型名と各集合のサイズが一致。
- DM1／VA2、VP3、その他が排他的で全686細胞を尽くす。
- 全個別発火数の和が、元の集団カウンタの同じ100 ms／1秒窓の和と40試行すべてで一致。
- 各集団の発火数を686で割った寄与の和が、元のPN平均に一致。
- OFF19〜20秒の外部刺激記録が0であることを確認。
- 図の確認、入力ハッシュと保存結果の対応を記録。神経コード・ライブ回路・2D版に変更はない。

Python 3とMatplotlib（図はNumPyも使用）。研究ワークツリーのルートから未作成の出力先を指定する。

```sh
LAB=tools/fly-body-lab/brain-pn-channels
PREVIOUS=tools/fly-body-lab/brain-pn-output/results
OUT=/tmp/pn-channel-results-new
python3 "$LAB/analyze.py" --previous "$PREVIOUS" --out "$OUT"
python3 "$LAB/plot.py" "$OUT"
```

`cohorts.json` は集団定義、`cells.csv` は18 PN×40試行の個別値、`metrics.csv` はDM1、VA2、両者、VP3、その他、全PNの集計、`summary.csv` は範囲表。`afferent-annotation-check.csv` は保存接続の構造的照合であり、TRNへの入力監査ではない。
