# DM1／VA2の4 PN：ON／OFF／再ONの時間応答

**既知正符号eLN→PNのOFF到来停止で、4 PNの時間応答を確認した。既定の参考条件を満たした組は8/8、個別4細胞がOFF指標で厳密に0だった組は8/8、OFF1秒以後の全区間で無発火だった組は8/8。**

[時間応答の図](results/four-PN-time-response.png) · [全16試行の指標](results/summary.csv) · [個別4細胞の指標](results/cells.csv)

## 今回の核と範囲

読み出す細胞は前回固定した **DM1_lPN 10176・10208、VA2_adPN 10390・10561** の4個体。前回の同じ条件を再実行し、それぞれの発火数を1 msごとに24.5秒間記録した。

比較は停止なしと、**OFF到来だけ既知の正符号eLN→PNを止める条件**の2つ。4seed（2026091701、2026091711、2026091721、2026091731）×入力利得1.0／0.5の同じ8組、計16試行。最初のseed・利得1.0で2条件の手順を検証し、実行ソースのハッシュを固定して残る7組へ展開した。

**読み出しは4 PNだが、停止先を新たに4 PNへ絞った試験ではない。** 前回と同じく全686 ALPNへ入る既知正符号ALLNの11,069辺（ACh 10,944＋octopamine 125）をOFF到来だけ止める。unclearと負入力は通す。ここで停止対象を変えると別の介入になるため、元の条件を維持した。

ONでは全入力を通す。前回のPN／LN→ORN停止を重ねず、TRN切断、温度の意味づけ、適応項、追加の抑圧は導入していない。`hungry` / `satiated` は以前と同じ入力利得の再現ラベル。

## 時間窓と判定

無入力0.5秒→ON1秒→OFF20秒→再ON1秒→再OFF2秒。刺激はDM1／VA2 ORNに基準60 Hz×入力利得。dt=0.5 ms、遅延2 ms、gain=0.65、KC gain=0.25、single worker、50 ms endTickは前回と同じ。

| 指標 | 固定した測り方 |
|---|---|
| 初回・再刺激ピーク | 各1秒ON内に完全に収まる10 ms／50 ms移動平均の最大値。1 msずつ移動 |
| 刺激後半 | 各ONの最後500 msの平均 |
| OFF1秒・再OFF1秒 | 各OFF後900〜1000 msの100 ms平均 |
| OFF20秒 | 初回OFF後19900〜20000 msの100 ms平均 |
| 個別細胞の静穏 | 平均に加え、4細胞それぞれの発火が0か確認 |
| 静穏の継続 | OFF1秒以後、次のON／記録終了までの全発火数も確認 |
| OFF後の最後の発火 | 最後に発火が入った1 msビンの終了時刻。厳密なスパイク時刻ではなく上端 |

以前の基準を再使用する。初回・再刺激の両ピーク幅は対応する対照の70%以上、刺激後半は対照の30%以上、OFFの参考静穏値は3 Hz以下。30%と3 Hzは以前の実験で置いた操作的参考値で、生理学的な確定閾値ではない。再刺激ピークは自分自身の初回ピークとの比も示し、OFF20秒から実際に立ち上がったかを確認する。0 Hzと3 Hz以下は別に記録し、集団平均の静穏を全細胞の無発火と読み替えない。

## 測定結果

| 4 PN平均の指標 | 停止なし（8試行） | 既知正符号eLNのOFF停止（8試行） |
|---|---:|---:|
| 初回ピーク10 ms | 450.00〜500.00 Hz | 450.00〜500.00 Hz |
| 初回ピーク50 ms | 410.00〜455.00 Hz | 410.00〜455.00 Hz |
| 初回刺激後半500 ms | 391.50〜429.50 Hz | 391.50〜429.50 Hz |
| OFF1秒 | 330.00〜350.00 Hz | 0.00〜0.00 Hz |
| OFF20秒 | 335.00〜352.50 Hz | 0.00〜0.00 Hz |
| 再刺激ピーク10 ms | 425.00〜500.00 Hz | 450.00〜500.00 Hz |
| 再刺激ピーク50 ms | 410.00〜450.00 Hz | 410.00〜450.00 Hz |
| 再刺激後半500 ms | 392.50〜432.00 Hz | 393.50〜432.50 Hz |
| 再OFF1秒 | 332.50〜352.50 Hz | 0.00〜0.00 Hz |

同じseed・同じ利得の対照との比。初回ピーク10／50 msと初回後半はすべて1.00。再刺激は、ピーク10 msが1.000〜1.118、50 msが0.988〜1.011、後半500 msが0.997〜1.006。再刺激ピークを自分の初回と比べると、10 msが1.000〜1.056、50 msが0.988〜1.011。平均値だけでなく個別4細胞の指標も保存した。

初回・再OFFを合わせた16区間のうち、OFF内に発火を一度も記録しなかった区間は4。発火があった区間でも、最後の発火ビンの上端は最大3 msだった。これは1 ms刻みの時刻範囲であり、厳密な発火時刻ではない。OFF1秒・OFF20秒・再OFF1秒が0であることに加え、OFF1秒以後の初回19秒間と再OFFの残り1秒間も、4個体すべて無発火だった。対照にはOFF中も活動が残った。

## ドギドへ進められる範囲

**この固定刺激条件では、独立したドギド3Dラボへ嗅覚読み出しを試験接続するための時間応答条件を満たした。** 初回刺激中の応答を保ち、OFFで個別4細胞が0になり、20秒後の再刺激で再び上がり、再OFFで再び0になる。

次は同じ4 PNと同じ到来規則を身体センサーへつなぐ小さな実装確認へ進める段階。今回ライブへの配線自体は行っていないので、身体側のタイミングと神経時刻の対応、検知信号のON／OFFが往復する実動作は未確認であり、本番採用済みとは扱わない。TRN切断や温度の意味づけを、この試験接続の前提として追加しない。

このOFF制御は、**試験の刺激スケジュールがON／OFFを教えている**。神経活動だけから匂いの消失を自律判定した試験ではない。ライブ接続では、身体側センサーの匂い入力状態に従って同じ到来規則を適用する方式として扱う。神経の残留出力を見てOFFを決める循環した実装にはしない。

今回の比較から、既知正符号eLN停止による回路修正が生体の嗅覚に正しい、他の匂い・強度・時系列でも同様、全PNが静まった、とはいわない。VP3やその他のPNを含む全体の残留と、指定した4 PNの読み出しは引き続き区別する。

## 記録の追加が回路を変えていないことの確認

前回の回復点は `5d6d7a0`。上流commit `6cfa30175003ef25da68a237d5eda958f8047b82`、接続データSHA256 `e33df182bed7a6f3ea279daf4790a82b05706d3d41e819a6a80c0473e8c559f3` を固定。

`PNTrial.java` へ個別4 PNのカウンタ読み取りとCSV出力だけを追加した。`readout-only.patch` にその差分を保存。前回の `PnInputProbe.java` とsolverの到来ゲートは変更していない。

- 全16試行で、元の毎1 ms集団・10 ORN発火、686 PN累積値、入力辺一覧、全区間の実到来件数、送信元発火、OFF19〜20秒の入力内訳、0.5 ms入力集計、境界記録、solver検証値の**9ファイルすべてが前回とバイト単位で一致**。
- 今回の4 PNの毎1 ms記録を累積すると、前回の4つの保存時点の各個体累積数へすべて一致。時刻と外部刺激も元の集団記録と一致。
- 4個体および4細胞平均のピークを累積和で算出し、別のNumPy畳み込みでも各ONの10／50 ms最大値が一致。後半・OFF1秒の窓も独立な配列平均で一致。
- 最初の2試行で固定した実行ソースのハッシュを全16試行終了時に再確認。モデルと入力ゲートの変更ではなく、時間記録の追加だけであることを確認。

全PNの発火・到来ファイルは前回と同一なので重複保存しない。今回の保存対象は新しい4 PN時間記録、既存出力との一致ハッシュ、検証記録、集計と図。再実行時の生出力は指定したrawディレクトリへ全て残す。以前の同一ファイルは `brain-pn-output/results` を参照する。

`*-four-PN.csv` はend_msで終わる直前1 msの各細胞の発火数。`report.json` は4細胞平均と個別細胞の指標・ピーク窓・対照比・条件判定、`summary.csv` は平均指標、`cells.csv` は個別指標。図は見やすい10 msの固定ビン、判定ピークは1 ms移動の窓なので同じものとして扱わない。

## 再現

Java 25、Python 3＋NumPy＋Matplotlib。研究worktreeルートから、未作成の出力先を指定する。

```sh
LAB=tools/fly-body-lab/brain-pn-time
UPSTREAM=.fly-research/upstream/blendi-remade--fly-brain-minecraft
PREVIOUS=tools/fly-body-lab/brain-pn-output/results
ORN_IDS=tools/fly-body-lab/brain-orn-entry/results/active-ORN-body-ids.txt
JDK=/path/to/jdk/bin
BUILD=/tmp/pn-time-build-new
RAW=/tmp/pn-time-raw-new
OUT=/tmp/pn-time-results-new
python3 "$LAB/build.py" --upstream "$UPSTREAM" --output "$BUILD" --jdk "$JDK"
python3 "$LAB/run.py" --build "$BUILD" --previous "$PREVIOUS" --orn-ids "$ORN_IDS" --data "$UPSTREAM/src/main/resources/connectome/malecns-v1.0.flyb.gz" --java "$JDK/java" --raw "$RAW" --out "$OUT"
python3 "$LAB/analyze.py" "$OUT"
python3 "$LAB/plot.py" "$OUT"
```
