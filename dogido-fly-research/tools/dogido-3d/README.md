# 丸いドギド・Blender試作 v03

## v03：左右の手のパタパタ

最新版 `dogido-round-v03.blend` に `Rig - 左右の手を動かす` を追加。ポーズモードで `Hand.L` / `Hand.R` を別々に動かせる。体は一体のまま、手の付け根から先だけに滑らかに変形の重みを付けている。顔には骨格変形を適用していない。正面左右の対称化はv02を継承。

タイムライン1〜96で、体の浮遊に合わせて約1.33秒周期・±23度の手の往復を3回行う。体の浮遊は親の `Dogido - 全体移動`、手は独立した骨のアニメーションで、それぞれ編集できる。モーションは試作値。原画、元のメッシュ形状、顔のUV、透過・発光設定を変更せず、v01/v02も別名で保存したまま。

`rig_hands.py` で作成。上下端の評価済みメッシュを比較し、手先の移動を確認、体の中央の変形は0。`hands-up-v03.png` / `hands-down-v03.png` で端姿勢を確認し、`hand-flap-v03.mp4` は4秒の繰り返し確認動画（12fps、音声なし）。`flap-frames-v03/` は動画用の中間レンダリング。

## v02：右顔を基準にした調整

作者から「2Dは斜め顔なのでずらしていた。3Dでは右顔に合わせて軽く左右対称に」と指定を受け、向かって右側の目・眉・頬の形を3Dの左右へ割り当て、口を体の中心に合わせた。右側のパーツの大きさと高さは維持。変更は顔のUV（原画を表面のどこへ載せるか）のみで、体・手・顔面メッシュ・質感・発光は変更していない。3D顔のみに明示指定された対称化であり、2D画像全体を反転するものではない。

顔調整版は `dogido-round-v02.blend`。比較ページは `day-v02.png` / `night-v02.png` / `front-v02.png` / `side-v02.png` を使用。`adjust_face.py` はv01を読み、別名のv02を作る。v01と2D原画は保存したまま。形状・配置と原画が変更されていないこと、顔の左右UVの一致を検査している。

## 元の立体試作

基本形の顔を残した、球に近い前後の厚みを持つ立体試作。足は付けず、小さな手と浮遊する体。横・背面・手の立体形状は新しい仮案で、作者の確認前。

- `dogido-round-v01.blend`：Blender 5.2.1で保存した編集用ファイル。
- `day.png` / `night.png`：同じモデルを昼／暗所の照明で描画。
- `side.png`：横からの厚み確認。
- `build.py`：別の新規Blenderセッションで試作を再構築するスクリプト。再実行はこのフォルダの試作出力を更新するため、手修正したblendは別名保存してから使う。

## 使い方

`.blend` を開き、シーン選択で `Day - 昼の質感` / `Night - 暗所の淡い発光` を切り替える。テンキー0でカメラ視点、F12で描画。体を選んで回り込めば横・背面も確認できる。タイムライン1〜96に緩い上下浮遊を付けてある。

`Dogido - 全体移動` のカスタムプロパティで `body_opacity`（初期値0.86、不透明度）と `soft_glow`（初期値0.38、自己発光）を変更できる。体と手の表面は一体化し、透過で付け根が二重にならないようにした。元の手の構築部品は非表示で残す。

基本形の原画 `character.png` を無変更でblend内に梱包。顔の色の部分だけをマテリアルで選び、球面に沿わせて表示する。生成した顔は使用していない。v01は原画の非対称な顔をそのまま使用し、v02は上記の右側基準の対称化のみを適用。顔は独立オブジェクト。輪郭の原画をそのまま厚く押し出したモデルではなく、丸い立体としての解釈案。

体は少し透過する柔らかいクリーム色。自己発光と控えめな縁の明るさを持ち、暗所シーンのみ淡い光のにじみを合成する。自己発光は一定で、暗くなると相対的に目立つ仕組み。ゲーム内の明るさ検知を接続したものではない。
