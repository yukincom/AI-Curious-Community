# 通常対話・4系統×7seedの結果

**既知の診断データによる比較。未知の実機精度ではありません。**

28本は同じseed43 checkpointからの追加学習。7seedは学習順等の反復であり、7種類の基盤初期化ではありません。

学習28本、4系統合成35本、同方式の7seed重み平均9本、元モデル1本の計73候補を比較しました。
