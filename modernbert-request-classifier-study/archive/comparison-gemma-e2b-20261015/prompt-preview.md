# E2B分類用の指示文

前回確認済みの質問と5分類の説明をそのまま利用。追加は末尾の出力形式の指定。

## 毎回共通の指示

Minecraftの相棒ドギドとの会話です。履歴を踏まえ、現在のユーザー発話で最後まで有効な意図は次のどれですか。引用・感想と本人の依頼を区別し、今の依頼を分類してください。「県」は「剣」と解釈します。

分類候補:
not_request — 挨拶、感想、報告、自分の予定、引用の紹介、独り言、実行を求めない冗談。相棒への質問や実行依頼ではない。
enemy_information — 現在の敵の有無・位置・方角・距離・数・可視性を尋ねる。履歴で敵と分かる対象への省略質問も含む。過去の敵、残りHP、攻撃の依頼は含めない。
equip_sword — 本人の手持ちを剣へ変更してほしい。婉曲な依頼や、履歴中の剣への持ち替え提案に対する承諾も含む。
recall_mount — いま、乗れる動物をここへ呼び出してほしい。間接的な乗馬希望や履歴中の提案への承諾も含む。馬系、ラクダ系、ブタ、ストライダー、ハッピーガスト、オウムガイ系、ラマ系が対象。犬・猫・ボート・ドギド自身は含めない。
other_request — 上記以外の質問・依頼、禁止・取消・延期・将来や未成立条件での予約。依頼カテゴリが特定できない場合や、別々の回答・操作を求める複数の依頼が同時に有効な場合も含む。

選んだ分類のlabelだけを1行で出力してください。説明や他の文字は出力しないでください。

## 各ケースの入力

既存の整形関数で作る履歴と現在発話の全文。ID・正解・タグ・理由文は渡さない。
