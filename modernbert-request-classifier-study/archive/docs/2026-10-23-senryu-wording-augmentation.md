# 川柳の行指定と具体変更：言い回しの補強

**後続：[890件版・3シードの学習結果](2026-10-23-colab-23class-890-results.md)を受領済み。以下は学習前の教材作成記録。**

## 作成内容

上・中・下それぞれ、行指定24件と具体変更24件を追加。合計72対144件、24系統。行呼称だけの機械的な置換ではなく、各行ごとに文を作成した。全例が今回作成した合成文で、ユーザーの実発話やSTTログとして扱わない。

| 系統の例 | 行指定 | 具体変更 |
|---|---|---|
| 好み | 上の句は、別の言葉の方がいいな。 | 上の句は、石の橋の方がいいな。 |
| 希望 | 二行目だけでも手直しできたらうれしいんだけど。 | 二行目を光がこぼれるにできたらうれしいんだけど。 |
| 現在句の引用 | 下の句の今の「雪あかり」だと、終わり方が急に感じる。 | 下の句の今の「雪あかり」を「風のあと」に替えようかな。 |
| 短い省略形 | 中7、ここ再考で。 | 中7、草を踏みしめで。 |

ほかに、丁寧な疑問形、協働の提案、候補の質問、言い直し、語順の入れ替え、意味の質問、抽象的な方向、リズムや長さの感想、未決定、口語、前置き、対象行の限定、句中の一部分への言及、操作語を含む句、情景の希望、強調、ためらいを含む。

- 現在句の語を引用しても、新しい置換語がなければ行指定。
- 「静かな感じに」「言いやすくしたい」等の方向だけなら行指定。
- 候補を提示する疑問形・希望・提案でも、具体的な置換語があれば具体変更。
- 引用符のある例は両側15/72件、引用符のない例は両側57/72件。
- 音数・5/7/5との一致・句の品質で教材を採否しない。

同じ系統の上・中・下の6文を一つのgroupにまとめ、24groupすべてをtrainへ追加した。72対を独立した72文型の証拠とは数えない。
