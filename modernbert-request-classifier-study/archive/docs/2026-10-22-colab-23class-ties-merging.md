# 最終23分類層を固定したTIES-Merging（2026-10-22）

**指定の9構成では、第8層交換版の62/79件・macro F1 0.8343を上回らなかった。** TIESの正解数最多は50%保持・倍率1.0と80%保持・倍率1.0の61/79件。TIES内でmacro F1が最高なのは20%保持・倍率1.2の0.8277だが、正解数は60/79件だった。

最終の `classifier.weight` と `classifier.bias` はすべて新650件モデルと完全一致。既存dev79件だけで比較し、追加学習・test評価・本体採用は行っていない。

## 合成した範囲と方法

| 範囲 | テンソル数 | パラメーター数 | 処理 |
|---|---:|---:|---|
| 埋め込み、Transformer第1〜10層、最終正規化、分類前のhead | 64 | 36,771,328 | 共通ベースからの差分にTIES |
| 最終23分類のclassifier | 2 | 5,911 | 新モデルからそのままコピー |

旧536件モデル・新650件モデルは同じ `sbintuitions/modernbert-ja-30m`、revision `8cb03f54cb9e30e72459e5f1cedc6d89c7d8dcb5`、seed 43、23分類の順序で学習されている。共通の学習前モデルは既存のローカルキャッシュから読み込んだ。初期classifierを推定する処理は使っていない。

各モデルについて64テンソルを名前順に連結し、学習前からの変化量を一つのベクトルにする。その絶対値で小さな変化を除き、残った差分の合計で符号を選び、その符号と一致する非ゼロ差分だけ平均する。最後に倍率を掛けて共通ベースへ足す。テンソル別の間引きや、旧新モデル間の混合比の指定ではない。

```text
delta_old = old - base
delta_new = new - base
merged_shared = base + scale * TIES(delta_old, delta_new)
merged_classifier = new_classifier
```

[原論文](https://proceedings.neurips.cc/paper_files/paper/2023/hash/1644c9af28ab7916874f6fd6228a9bcf-Abstract-Conference.html)と[作者実装](https://github.com/prateeky2806/ties-merging/blob/44e7891fc84f3de7e4caa52664cd864ca3715e91/src/utils/merge_utils.py)の `topk / mass / dis-mean` を参照。作者のCLIはT5/T0を対象にしているため、既存ModernBERT評価処理へ合成計算を接続した。作者実装の該当4関数を抽出し、3つの保持率それぞれで36,771,328個の合成差分すべてが完全一致することを確認した。参照ソースとBSDライセンスも保存。

作者実装に合わせて `abs(delta) >= 閾値` を残すため、閾値と同じ値が多いと指定率を超える。今回の実保持率は次のとおり。

| 指定保持率 | 旧モデルの実保持率 | 新モデルの実保持率 | 両方に残り符号が逆のパラメーター数 |
|---|---:|---:|---:|
| 20% | 20.0000% | 20.0000% | 1,527,055 |
| 50% | 53.2667% | 53.3609% | 4,037,919 |
| 80% | 80.0955% | 80.1353% | 4,060,688 |

これらは差分の数値上の競合であり、分類上の誤りの数ではない。

### 正解数最多：50%・倍率1.0（80%・倍率1.0も同じ予測ラベル）

- 第8層版との比較：改善1件、新たな誤り2件、誤分類間の変化1件。
- 改善：「うーんと。。。上５・・・変えませんか？」を上のチェンジから上の行指定へ。
- 悪化：「村人は何人いる？」「熱帯魚は何匹いる？」を対象外から敵情報へ。敵情報の誤検出が1→3件、対象外の正解が4→2件になった。
- 誤分類間の変化：「後ろを振り向いて、私が見てる方を見て。」はプレイヤー注視→後ろを見るへ変化。正解の「同じ遠景を見る」には届かない。
- 剣5/5・誤検出0、乗り物5/5・誤検出1、ドギド3/3・誤検出2は第8層版と同じ。

### macro F1最高：20%・倍率1.2

- 第8層版との比較：改善2件、新たな誤り4件、誤分類間の変化1件。
- 上の行指定に加え、「私と同じ方を向いてみて。遠くにおもしろいものがあるよ。」をプレイヤー注視から同じ遠景へ改善。
- 「村人は何人いる？」「熱帯魚は何匹いる？」「ゾンビ出たら泣いちゃう？」が敵情報になり、下の行指定1件もチェンジへ戻った。
- 「この松明を壁に設置してくれる？」は対象注視から乗り物呼び出しへ誤分類が変化。乗り物の誤検出は1→2件。
- 剣とドギドのTP/FPは第8層版と同じだが、対象外・敵情報・乗り物・下の行指定の境界が悪化した。

今回の9構成では、第8層交換版が正解数・macro F1の両方で上回った。TIESで改善した個別入力もあるが、この結果から第8層版をTIESへ置き換える根拠は得られなかった。
