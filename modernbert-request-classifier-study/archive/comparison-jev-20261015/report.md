# 日本語Jev風BERTと現行30Mの199件比較

**実施日:** 2026-10-15。両モデルを同一の199件に実行し、保存予測と時間記録を再集計済み。

対象は [`argos1111/modernbert-ja-310m-jev`](https://huggingface.co/argos1111/modernbert-ja-310m-jev) の非公式ローカルモデル。**TypeSafeのJev本体・外部APIは使用していない。** モデルが公開前に受けた判断タスク学習はそのまま利用し、ドギド用の追加学習・重み変更・評価後のプロンプト探索は行っていない。

## 計測条件

- Apple M4 Max、メモリ64 GiB。CPUのみ、float32、SDPA、PyTorch内4スレッド／相互1スレッド。
- 入力は同じ本文と履歴。既存 `dataset.model_example()` を共用し、ID・正解・タグ・旧予測はモデル入力へ渡していない。
- 30Mは本文1件を1回。日本語Jev風BERTは公式形式「質問＋状況」と5候補のペアを同じbatchで1回。候補数で時間を割らず、1依頼全体の時間を比較した。
- 各モデル20件のウォームアップ後に199件を予測。速度は別に199件×5周＝995計測／モデル。各周のケース順は同じ固定乱数で並べ替え、モデルの実行順を交互にした。各ブロック直前に4件を追加ウォームアップ。
- 計測に含むもの：入力整形、tokenize、推論、softmax、最大候補選択。含まないもの：Python起動、モデル読み込み、IPC、サーバー待ち、結果保存。
- 入力切り詰め0件。最長系列は30M 154 token、日本語Jev風BERT 277 token。
- 常駐サービスの停止・再起動・モデル切り替えやMinecraftへの操作、本体への分類器接続は行っていない。バックグラウンド負荷を排除した専用機測定ではない。
- 保存済み30Mの全199予測と今回の予測が完全一致。反復計測で予測の揺れ0件。双方の重み・元データ・確認済みプロンプトのハッシュは実行後も一致。
- 実パラメータ数：30M 36,772,613、日本語Jev風BERT 315,203,329。
- バージョン：PyTorch 2.14.1、Transformers 5.19.0、tokenizers 0.23.3。
- Jev風BERTの固定revision：`07cda23579443e7a33c0f474114279fa032340d6`。
- ユーザー指定の文言修正を反映したprompt SHA-256：`a402e5c13ab9b7860052234af8f30d25da9324d52a469384cb1693dcfb6fc49b`。

## 解釈の範囲

- 199件の内訳は合成193件、観測発話5件、ユーザー作例1件。実会話の発生頻度を代表する統計ではない。
- `moving` 60件は現行30Mのseed選択に使われた診断群。`regression` は既知の失敗に基づく回帰群。全199件を完全な未使用テストと呼ばない。
- 現行30Mはドギドの分類用に学習済み、日本語Jev風BERTは今回のドギド用追加学習なし。この用途での現在の実用性能を比較しており、モデル構造や規模だけの優劣は判定していない。
- Jev風BERTの結果は、この固定された質問・候補文言での成績。文言の最適化や別モデル設定の網羅的な比較は行っていない。
- softmax値は保存しているが、正答確率としての校正は検証していない。

## 保存物と再現

- `prompt.json` / `prompt-review.json`：質問・選択肢とユーザー修正の記録。
- `cases.json` / `input-preview.jsonl`：同じ199件と実入力全文。
- `30m-predictions.json` / `jev-predictions.json`：全件の予測・logit・softmax値。
- `timings.jsonl` / `summary.json`：全1990計測と集計。
- `paired-cases.json` / `errors.md`：予測変化と両モデルの誤分類。
- `model-snapshot.json` / `hf-metadata.json`：公開モデルrevision・全取得ファイルのハッシュ。重み自体は既存Hugging Faceキャッシュに保存。
- `benchmark.py`：既存の整形・集計を使う比較処理。`make_report.py`：推論せず保存結果の一致・回数・指標を再検証。
- `review.json` / `verification.json`：独立静的レビューと再集計検証。

既存プロジェクトのルートを作業ディレクトリにし、PyTorch等が入ったPythonで実行する。`model-snapshot.json` は取得済みキャッシュの場所、`preparation.json` は元199件の場所を記録している。別の環境では同じrevision・ハッシュのファイルを用意して、その保存場所を合わせる。

```sh
python comparison-jev-20261015/benchmark.py --approved-prompt-sha256 a402e5c13ab9b7860052234af8f30d25da9324d52a469384cb1693dcfb6fc49b
python comparison-jev-20261015/make_report.py
```
