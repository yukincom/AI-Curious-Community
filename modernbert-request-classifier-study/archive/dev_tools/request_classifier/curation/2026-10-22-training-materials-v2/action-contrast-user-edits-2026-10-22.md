# 剣の復帰と、ドギドの呼び寄せ・乗り物の召喚

剣42例を復帰。新しい合成は32組のドギド本人への接近／乗り物召喚と、対象外8例。

合成例は実機ログではない。同じ組の発話は同じgroupに保持。動作の説明は注釈であり、モデルには発話と整数ラベルだけを渡す。

## 対象外の対照

| 発話 | 理由 | 出典ID |
|---|---|---|
| 今は乗り物もドギドも呼ばなくていい。 | どちらの移動も依頼しない取消。 | contrast:contrast_113 |
| ドギド、今はついてこなくていいよ。 | 本人への追従・接近を取りやめる。 | contrast:contrast_114 |
| 馬はもう呼び出したから、今は追加で呼ばないで。 | 実行済み報告と追加呼出しの取消。 | contrast:contrast_115 |
| ドギドが隣まで来たね。 | 接近済みの報告で新しい移動依頼はない。 | contrast:contrast_116 |
| 馬はさっきここへワープしてきたね。 | 乗り物の移動済み報告。 | contrast:contrast_117 |
| 『ドギド、おいで』という台詞があったね。 | 呼びかけを引用した感想で、今の移動依頼ではない。 | contrast:contrast_118 |
| 猫をここへ召喚して。 | ユーザーが呼べないと確認した猫の依頼。乗り物の対象外。 | contrast:contrast_119 |
| 近くの猫を私の横にワープさせて。 | 近距離でも猫は呼出し対象外。距離やワープという語で乗り物にしない。 | contrast:contrast_120 |
