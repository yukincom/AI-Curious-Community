# 川柳の行指定と具体変更：言い回しの補強

2026-10-23のユーザー依頼に基づき、**24系統・72対・144件**を作成。[全文を対で読む](additions-review.md)。すべてCodexが作成した合成文で、実機ログやユーザー原文ではない。

## 分類の境界

- `senryu_line_*`：対象行への感想・相談・変更要求。変更後の具体的な語句は指定していない。
- `senryu_change_*`：対象行と、新しく使う具体的な語句を指定。候補の質問・希望・提案も含む。
- 現在句の引用は、それだけでは変更後の語句にならない。抽象的な雰囲気や長さの希望も行指定に含める。

例：「上の句は、別の言葉の方がいいな。」は行指定、「上の句は、石の橋の方がいいな。」は具体変更。

引用符を含む例は行指定・具体変更とも15/72件。引用符なしの具体変更も57件ある。句中に「変えないで」「もう終わろうか」等を含む場合も、発話全体で現在句の引用か新しい候補かを区別する。
