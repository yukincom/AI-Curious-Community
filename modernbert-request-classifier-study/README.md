# ModernBERT-Jaによる日本語依頼分類：教材・追加学習・モデル合成の記録

実験期間：**2026-10-14〜24**。Minecraftの相棒[ドギド](https://github.com/yukincom/DokiDoki_Dogido)で、現在の発話からモブ情報、剣の持ち替え、乗用動物の呼出し、視線、川柳の相談操作などを読み取る、小型日本語分類器の開発記録です。

基盤は `sbintuitions/modernbert-ja-30m`。教材と分類の定義を見直しながら、全パラメータの追加学習、分類層の一部だけの更新、重み平均、層交換、共通モデルから分岐した専門別学習を比較しました。このREADMEで経緯を概観し、各段階の資料から条件・教材・保存予測まで確認できます。

## 現在の構成

2026-10-24の採用モデルは次の2本です。既存の川柳ワークショップ状態から入力先を決め、**一つの発話は片方の分類器だけに渡します**。分類器は発話の用途を読み、対象・現在状態・操作・保存は本体が管理します。

| 用途 | 教材総数（train / dev / test） | 採用モデル | 固定testの正解数 |
|---|---:|---|---:|
| 川柳の行指定・具体変更・終了・対象外の8分類 | 424（349 / 39 / 36） | 川柳版seed42 | 36/36 |
| モブ情報・剣・乗用動物・接近・視線・対象外の16分類 | 914（818 / 46 / 50） | 通常版`seed48-mob` | 45/50 |

`mob`はモブ情報の教材を重点的に再提示した学習設定の名前で、**出力は通常用の全16分類**です。実行時に4本の専門モデルを呼び分ける構成ではありません。川柳と通常の切替、モデルの採用、実機確認の範囲は[本体への接続記録](updates/2026-10-24/docs/2026-10-24-bert-mode-routing.md)にまとめています。

これらのdev/testは、開発中に失敗分析と教材設計で参照した固定診断です。未知の実機発話に対する独立評価とは区別します。旧23分類、川柳8分類、通常16分類は評価集合が異なるため、上の数値を単純な性能順位にはできません。

## どの順に、学習方法を変えたか

`train`は重みの更新、`dev`はモデル・epoch・合成候補の選択、`test`は選択後の診断に使った例です。seedは学習時の乱数設定を指します。以下では、教材総数と重み更新に使った件数を分けています。

## 最後の4系統学習で変えた点

前の3専門試行では、専門ごとに既存教材の一部を選んでいました。最後の試行は、**全教材を各モデルに残したうえで、担当例の提示回数を増やす**方式です。

- 旧train482件に336件を追加。内訳は新作328件と、旧教材から再利用した8件。共有train818件、dev46件、test50件です。通常578件版以降のdev/testは同じ本文・正解・分割を維持しました。
- 4系統は「視線＋ドギド接近」「乗用動物」「剣」「モブ情報」。担当例と関連する対象外例を、同じepoch内でもう一度提示します。1 epochの提示回数は順に1,184・945・937・942回ですが、各モデルの異なる教材は818件です。
- 全28本を、学習済みの通常578件版seed43の**同一の全重み**から開始しました。7seedは学習順などを変える反復で、分類層を7通りに初期化してから合成したものではありません。
- 比較は、元モデル1本、学習単体28本、同seed内の4専門合成35本、同方式の7seed重み平均9本の計73候補。dev macro F1、loss、事前に固定した順序で選び、選択記録を保存してからtestを診断しました。

合成したのは**モデルの重み**です。推論結果の多数決ではありません。Task Arithmeticでは「専門モデル−共通初期モデル」の差分を加算し、係数0.25・0.5・1を比較しました。4本に係数0.25を使うと、4専門の等重み平均になります。TIESでは大きい更新を上位20%残し、更新方向の合意を取った差分を係数0.5・1で加えています。

### 選択結果と、合成方式の安定性

| devで固定した候補 | dev正解 | dev macro F1 | test正解 |
|---|---:|---:|---:|
| 比較元：通常578件版seed43 | 39/46 | 0.8930 | 41/50 |
| 総合・単体の選択：`seed48-mob` | 42/46 | 0.9428 | 45/50 |
| 4専門合成の選択：`seed43-ties20-half` | 42/46 | 0.9291 | 44/50 |
| 7seed平均devで選んだ方式の重み平均：`mean7-ties20-half` | 41/46 | 0.9188 | 45/50 |

4専門の単純平均は、7seedのtest正解率が**92.29% ± 0.76ポイント**（平均±標本標準偏差）でした。6seedは46/50で50件すべて同じ予測、残るseed46は47/50です。これは固定50件に対するseed間の安定性です。testの成績を見て、事前の選定モデルを単純平均へ変更してはいません。

係数1で4本の差分を足す方式は、平均45.14%まで低下しました。`not_target`への偏りも強く、重みを合成するだけで改善するとは言えません。

## 結果から言えること・残っていること

- **教材補強は他用途にも影響する。** 目的の依頼を拾えるようになっても、別の発話を操作へ誤分類する場合があります。正解数に加え、分類別成績・誤流入・全誤分類を保存しています。
- **合成前の学習経路を区別する必要がある。** 独立に学習したモデルの平均と、共通の学習済み重みから分岐したモデルの合成では結果が異なりました。この比較だけで内部表現の対応関係や悪化原因を確定はしていません。
- **最後の改善の原因はまだ分離できていない。** 教材追加、担当例の再提示、学習量が同時に変わっています。同じ818件を通常の提示比率で追加学習した対照がないため、改善を専門化や合成だけの効果とは結論できません。
- **少数例による評価の変動が大きい。** 通常testは16分類中7分類が各1件です。正解率と、各分類を均等に評価するmacro F1では順位が変わります。seed間の標準偏差も、未知入力への精度の信頼区間ではありません。
- **取りこぼしは残る。** 通常の採用モデルには、引用中の命令と今回の依頼、ドギドの接近と注視、前・左の方向表現などの誤りがあります。川柳にも未対応の終了表現があり、固定testの満点は任意の終了文を認識する保証ではありません。
