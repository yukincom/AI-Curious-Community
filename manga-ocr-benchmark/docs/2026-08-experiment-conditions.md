# 実験条件と数値の読み方

実験記録: 2026-08-23〜24。公開用整理: 2026-10-20。構成比較CSVには2026-10-14のGemma4 26B-A4B比較も追記しています。

この資料は保存済みの実験記録から数値と条件を取り出したものです。公開時にOCR推論を再実行していません。原資料や個別ページとの対応は公開しません。

## 1. ページ全体の比較

対象: 通常評価32ページ、低コントラスト・紙面劣化のストレステスト1ページ。通常評価の原稿分類は、鉛筆・生ネーム17、清書済み漫画9、清書済みデジタル手書き5、濃い手書きネーム1ページです。斜めのコマ構造を含む要分析ページも通常評価に含みます。

CSVの「通常評価（32ページ）」はストレス1ページを含みません。各分類と全体は重複する集計なので足し合わせないでください。全7条件・42行の集計数値は、公開用整理時に保存済みのページ別数値から再集計して一致を確認しました。

評価単位はページです。検出・切り出し後の候補を、準備されたID順に連結して正解ページと比較します。検出漏れ、切り出し、順序、認識の影響を含み、文字認識器単体の性能ではありません。参照IDに対応しない余分な候補は集計に入りません。

### 条件

- NDLOCR-Lite、YomiToku、Baberu OCR、PaddleOCRの保存済み出力。
- Baberu＋Paddleの候補をGemma E2Bで統合した出力。
- Baberu出力に漫画向け規則置換を加えた条件。
- 統合出力に空出力・長さ・反復・候補との類似度によるガードを適用し、必要時に既存候補へ戻してから漫画向け規則置換を加えた条件。

表の「規則ベース後処理」は文字列の置換や句読点変更を含みます。Unicodeの表記統一だけの処理ではありません。公開名はこの区別を明確にするため整理しました。数値は変更していません。これらの推論・後処理を再現するプログラムは今回の公開範囲に含めていません。

### 指標

正解と出力の両側にNFKCを適用し、すべての空白を除去します。

- CER: 文字単位の挿入・削除・置換を各1とするLevenshtein距離 ÷ 正解文字数。挿入が多いと1（100%）を超えます。
- micro CER: 全ページの編集距離合計 ÷ 正解文字数合計。
- macro CER: ページCERの単純平均。
- 文字F1: 最長共通部分列（LCS）長から計算するrecallとprecisionの調和平均。順序を考慮します。
- macro F1: ページF1の単純平均。作家平均・分類平均ではありません。
- 句読点中立CER: NFKCと空白除去後、英数字等のisalnum該当文字、U+3040–U+30FF、U+3400–U+9FFFだけを残して再採点します。Unicode分類ですべての句読点を除く処理とは異なり、カナ範囲内の記号が残る場合があります。

正解が欠落するページや、正規化後の正解が空になるページは元の評価対象から除外されます。文字数はPythonのUnicode文字列の長さで、書記素クラスタ数ではありません。

## 2. 吹き出し入力の構成比較（8月・10月）

[構成比較CSV](../results/bubble-configuration-comparisons.csv)は、stageとscopeで条件を示す形式に揃えています。旧表の全44行に含まれた比較条件と数値を保ち、8月32条件の正規化前後をそれぞれ別行にした64行と、10月の12行、計76行を収録しています。評価条件を1行ずつ示すための並べ替えであり、実験を追加実行したものではありません。

### 表の列

- stage: 認識器、入力候補から統合モデルへの流れ、または追加補正の方式です。矢印の左側が入力候補、右側が統合・確認モデルです。E2B／E4BはGemma4のモデル区分で、26BはGemma4 26B-A4Bに統一しています。
- scope: 比較の目的や処理段階、対象、採点単位、正規化条件を日本語で示しています。同じモデルでも、忠実転記と文脈修正候補、指示言語、入力文脈、初回と再測定を区別しています。
- pages / bubbles: 対象ページ数と入力領域数です。8月は対応済みの26吹き出し、10月は保存済み切り抜き領域の数を示します。
- truth_chars / output_chars: 各行の正規化条件を適用した参照・出力文字数です。
- edit_distance: 採点単位ごとの編集距離の合計です。8月は吹き出し、10月はページが単位です。
- exact_items: 完全一致した採点単位の数です。8月は26吹き出し中、10月はpages列に示すページ数のうち何ページかを数えています。
- micro_cer: edit_distance ÷ truth_charsの比率です。0.5554597701149425は約55.55%です。保存済みの整数値から算出し、丸め済み百分率から逆算していません。
- recorded_seconds: 記録された秒数を数値で示します。計測範囲は下記「時間」を参照してください。

### 8月：4ページ・26吹き出し

検出結果と参照本文を対応できた26吹き出しを採点した探索的な実験です。切り出せなかった文字や対応できない領域を含めたページ全体CERではありません。

scopeの末尾で、次の2条件を区別します。

- 吹き出し：空白除去 — 正解・出力の空白だけを除去します。旧表のrawに対応します。
- 吹き出し：出力正規化 — 出力側へNFC、全角ASCII（U+FF01–U+FF5E）の半角化、全角空白の変換を適用し、両側の空白を除去します。正解はあらかじめ基準表記で作成されています。旧表のnormalizedに対応し、両側NFKCとは異なります。

両行は同じOCR出力を異なる条件で採点したものです。新しいOCR推論ではなく、所要時間も同じ記録の再掲なので足し合わせません。8月の14比較群・32条件をすべて残しており、構成や処理段階が異なる場合は数値が同じでも別行です。同じ保存済み基準結果が複数の比較群に現れる場合も、独立した反復実験として平均しないでください。

### 構成と処理段階

- Baberu、Paddle、YomiToku、NDLOCRはOCR候補の出所です。「直接OCR」は画像からの認識、「忠実転記」は表記を保つ選択結果、「文脈修正候補」は文脈を踏まえた修正案です。
- 「隣接候補」「隣接本文候補」は隣接する吹き出しの文脈を使う条件、「3吹き出し窓」は3領域を使う条件です。単独切り抜き、ラフネーム向け指示、縦書き、日本語・英語指示も表示名で区別しています。
- 「疑わしい候補だけ追加処理」は追加処理対象を絞る条件です。
- 「限定補正」は機械生成した限定候補から選択する追加補正です。「限定補正比較・追加補正前」はBaberu＋Paddle→Gemma4 E2Bの標準統合、「Gemma4 E2B→E4B（段階的な限定補正）」はE2Bで据え置いた候補をE4Bで追加確認する条件です。

### 10月：Gemma4 26B-A4Bと保存済みBaberu

末尾12行は2026-10-14の初回・再測定について、通常評価・ストレステスト・全件の各集計と保存済みBaberuを並べたものです。[実行条件と詳細](2026-10-14-gemma-26b.md)を参照してください。

8月と10月はいずれも切り抜き領域を入力しますが、8月は4ページ・対応済み26吹き出しの個別採点、10月は通常28ページ・229領域の出力をページごとに連結した採点です。ストレスを含むと29ページ・239領域です。入力方式が共通でも、対象と採点単位を同一条件として扱わないでください。

10月のscope末尾「ページ：両側NFKC」は、連結した正解・出力の両方へNFKCと空白除去を適用して採点することを示します。初回の未知文字マーカー指定と、指定を外した再測定はscopeで区別しています。Baberuの初回・再測定の比較基準は同じ保存済み結果の再掲です。

通常評価、ストレステスト、全件（ストレス含む）は重複する集計です。合算したり、異なる評価単位のCERを平均したりしないでください。

### 時間

recorded_secondsは従来の時間列からs表記だけを外したもので、精度を補ったり推論を測り直したりしていません。

8月の単体OCRは認識処理、統合条件は主に最終統合処理の時間で、入力候補をすべて新規作成する総時間ではありません。モデル読込みも含みません。

限定補正比較では、追加補正前の25.01秒は標準統合、その他の行は追加補正の時間です。段階的な限定補正の25.32秒は追加補正の合計です。元記録では、この前に必要な候補生成・標準統合を含む全工程を約55.01秒としています。

10月のGemma4 26B-A4Bは領域ごとのHTTP往復、保存済みBaberuは過去に記録したモデル読込みを除く推論時間です。時間列をそのまま同等の総費用やモデル固有の速度として比較しないでください。

## 3. 1ページ・6吹き出しの段階別比較

正解53文字の同じページで、入力するOCR候補と統合モデルを変えた比較です。4ページ実験にも使われたページに対する探索で、独立な検証セットではありません。正解・出力の空白だけを除去します。

26行を収録しています。共通のNDLOCR結果を9行から1行、YomiToku結果を4行から1行にまとめ、重複した11行を整理しました。保存済みの入力経路、参照文字列、出力文字列と数値が一致することを確認した、同じ認識結果の再掲だけが対象です。

直接OCRの2条件と、11構成それぞれの忠実転記・文脈修正候補の22行はすべて残しています。モデル、入力候補、処理段階が異なれば、数値や出力が一致しても別の比較です。共通OCR結果を含む26行は、同一資料に対する条件比較であり、26回の独立した検証ではありません。

### 表示形式

[ページ全体の比較](../results/page-level-summary.csv)と同じように、stageとscopeで条件を示し、以降を数値列に揃えています。

- stage: 認識器または「入力候補→統合・確認モデル」。E2B／E4BはGemma4の実験上のモデル区分です。Gemma4 E2BとGemma4 E4Bの直接OCRを区別しています。
- scope: 共通OCR結果（再利用）、直接OCR、忠実転記、文脈修正候補。
- pages / bubbles: 対象ページ数と採点する吹き出し数。この表はすべて1ページ・6吹き出しです。
- truth_chars / output_chars: 空白除去後の参照・出力文字数。参照は各行53文字です。
- edit_distance / exact_items: 吹き出しごとの編集距離の合計と、完全一致した吹き出しの数。
- micro_cer: edit_distance ÷ truth_charsの比率です。0.22641509433962265は約22.6%で、元の百分率表示から単位を揃えています。保存済みの整数値から算出するため、丸め済み百分率からの逆算ではありません。

NDLOCRの共通行は、NDLOCRを入力候補に含む9構成の、統合・確認前の比較対象です。YomiTokuの共通行は、NDLOCR＋YomiToku＋直接OCR候補を使うE2B/E4Bの2構成と、YomiTokuのみを入力候補とするE2B/E4Bの2構成に対応します。表の中で共通行を繰り返す必要はありません。

1ページの反復利用による改善を、他のページへの汎化性能とみなすことはできません。

## 4. 5ページの合成OCR評価

2026-08-24の記録。同じRT-DETR検出領域と適応余白付き切り出しで、Baberu候補と合成後の出力を比較しました。ページ全体の指標で、正規化とCERは第1節と同じです。

micro CERはBaberu 82.9%、合成後88.1%。文字F1は29.6%から34.9%でした。このF1は全ページのLCS・文字数を合算して計算するmicro値で、第1節のmacro F1と異なります。CERとF1で改善方向が異なるため、一方だけで成功と判断できません。

3ページでCER改善、2ページで悪化しました。過大な検出領域と余白付き切り出しを渡した際の出力増加が、悪化例の記録にあります。原因の切り分けを完了した結果ではありません。

正解に領域座標がないため、検出のprecision/recallや領域単位の完全一致率は算出していません。個別ページの表や原資料との対応は収録していません。
